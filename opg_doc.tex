\begin{abstract}
This document describes the current \texttt{train\_gpt.py} implementation.
The model is a small language model for the Parameter Golf setting: the final
artifact is code plus compressed weights, capped at 16,000,000 bytes, and
evaluated by validation bits per byte.  The active backbone is a reversible
deep-equilibrium (RevDEQ) solve over one shared transformer-like block.  The
block uses dense soft routing over fully independent attention and MLP expert
banks, Parcae per-dimension damping and input gain, an NTP-only
mixture-of-softmaxes output head by default, int6 round-trip quantization, and
post-training fixed-point diagnostics.

The stability objective is local, not global: the code does not enforce a
global Banach contraction with ball projections or spectral-normalization caps.
The Jacobian-spectral-radius and finite-perturbation denoising regularizers
described in Section~\ref{sec:reg} (with coefficients
$\lambda_J=\texttt{lyapunov\_coef}$, $\lambda_D=\texttt{denoising\_coef}$) are
\emph{disabled by default} in the iter-89 baseline (both coefficients are
$0.0$); empirically the Parcae per-dimension $\bar A$ already bounds the local
spectral radius, making these explicit penalties redundant.  The terms remain
in code so they can be re-enabled without an architectural change.  The
theorem in Section~\ref{sec:lyapunov} records the self-contained mathematical
guarantee: if the Jacobian of the fixed-point map has spectral radius below
one at an equilibrium, that equilibrium is a local exponentially stable
attractor.
\end{abstract}

\section{Summary}
\label{sec:summary}

For token IDs $x\in\{0,\ldots,V-1\}^{B\times T}$, the model first builds an
input state $x_0\in\R^{B\times T\times D}$ from token embeddings and then
solves one shared block to equilibrium.  BigramHash is disabled by default, so
$x_0=\RMSNorm(E[x])$ in the default run.  For any tensor
$u\in\R^{B\times T\times D}$, define
\[
  \RMSUnit(u)
    = \frac{u}{\sqrt{D^{-1}\sum_{i=1}^D u_i^2+\epsilon}},
  \qquad
  \RMSNorm_{x_0}(x_0)=\RMSUnit(x_0)\odot g_{x0}.
\]
Here $g_{x0}$ is the learned per-channel scale
\texttt{x0\_inject\_norm\_weight}; it makes the input-injection normalization
learnable, while the RMS denominator remains parameter-free.

The shared block forms a dense-expert attention-plus-MLP update
$\Delta_\theta(z,x_0)$ using the parameter-free preconditioner
$h=\RMSUnit(z+x_0)$.  Parcae supplies per-channel retention, solver blend, and
input gain
\[
  \bar A=\epsilon_{\rm rev}+(1-\epsilon_{\rm rev})\exp(-\delta\odot a),
  \qquad
  \beta=1-\bar A,
  \qquad
  \bar B=\delta\odot b,
\]
with positive $\delta,a,b$ and $\epsilon_{\rm rev}=0.1$.  The fixed-point map is
\[
  T_\theta(z,x_0;\bar B)
    = \bar B\odot\RMSNorm_{x_0}(x_0)+\Delta_\theta(z,x_0).
\]
Thus $x_0$ conditions the block through both $h$ and the explicit
input-gain term; there is no unconditional residual $x_0+\Delta_\theta$.

RevDEQ iterates two states from $y_0=z_0=x_0$:
\[
\begin{aligned}
  y_{k+1} &= \bar A\odot y_k
          + \beta\odot T_\theta(z_k,x_0;\bar B),\\
  z_{k+1} &= \bar A\odot z_k
          + \beta\odot T_\theta(y_{k+1},x_0;\bar B).
\end{aligned}
\]
At a common equilibrium $y^\star=z^\star$, this reduces to
$z^\star=T_\theta(z^\star,x_0;\bar B)$.  The reversible backward pass
reconstructs earlier states by
\[
  z_k=\frac{z_{k+1}-\beta\odot T_\theta(y_{k+1},x_0;\bar B)}{\bar A},
  \qquad
  y_k=\frac{y_{k+1}-\beta\odot T_\theta(z_k,x_0;\bar B)}{\bar A}.
\]
The floor on $\bar A$ is required because $\bar A$ is the reverse denominator;
$\bar B$ is not floored because it is only an input gain inside
$T_\theta$.

The output head maps $h_{\rm out}=\RMSNorm(z^\star)$ to logits, with an
NTP-only mixture-of-softmaxes head by default.  The training objective is
\[
  \mathcal{L}
    = \mathcal{L}_{\rm main}
    + \mathcal{L}_{\rm jac}
    + \mathcal{L}_{\rm denoise}.
\]
Let $J^\star=\nabla_zT_\theta(z^\star,x_0;\bar B)$.  The Jacobian term uses a
Hutchinson probe $q=(J^\star)^\top v$ to estimate local sensitivity, then adds
a first-order surrogate through a live re-evaluation of $T_\theta$.  The
denoising term penalizes
$T_\theta(\stopgrad(z^\star)+\xi,x_0;\bar B)-\stopgrad(z^\star)$ for small
Gaussian $\xi$.  After training, validation checks the int6 round-trip artifact
and a fixed-point iteration-count sweep.  The stability guarantee is local:
if the spectral radius of $J^\star$ is below one, the reached equilibrium is a
locally exponentially stable attractor.

\subsection{Optimizer}
\label{sec:optimizer}

Matrix parameters use Muon with Polar-Express Newton--Schulz (PE-NS,
\texttt{use\_polar\_express\_ns=true} default, \texttt{muon\_backend\_steps=7}).
PE-NS uses minimax-tuned per-iteration polynomial coefficients that converge to
the matrix sign function faster than the stock Schulz-3 iteration; with 7
iterations this reaches the same tolerance as $\sim 12$ stock iterations,
giving slightly tighter orthogonalization at the same wall-clock cost.  Scalar
parameters use Adam ($\beta_1{=}0.85$, $\beta_2{=}0.90$); tied embeddings use
Adam at \texttt{tied\_embed\_lr=0.03}; Parcae raw parameters use a dedicated
\texttt{parcae\_lr=0.002}; the entmax blend logit (when entmax routing is
enabled) uses \texttt{entmax\_blend\_lr=0.002}.  Gradient clipping is applied
at norm $1.0$.

\paragraph{Practical implementation: PE-NS variance-regularizer interaction.}
The PE-NS default was briefly disabled in early iter 121 after iter 117 v2
NaN'd at step 30.  Bisection in iter 117 v3 identified the actual NaN driver
as the variance regularizer
$\mathcal{L}_{\mathrm{var}} = -\lambda \sum_e \mathrm{Var}_t(w(e \mid t))$
(introduced in H83) interacting with entmax-1.5: entmax produces exact-zero
routing weights above its threshold, and the negative-coefficient variance
term rewards larger token specialization, creating a positive feedback loop
that PE-NS's larger update spectrum amplifies.  Removing $\mathcal{L}_{\mathrm{var}}$
breaks the cascade; PE-NS @ 7 is then numerically stable and is the current
default since iter 117 v5 (PROMOTED 2026-04-30).  Code keeps both NS variants
behind \texttt{use\_polar\_express\_ns} for clean A/B comparison.

\section{Notation}
\label{sec:notation}

Let $B$ be batch size, $T$ sequence length, $D$ model width, and $V$ vocabulary
size.  Token IDs and next-token targets are
\[
  x,y \in \{0,\ldots,V-1\}^{B\times T}.
\]
The token embedding is $E[x]\in\R^{B\times T\times D}$.  BigramHash is present
in code but disabled by default.  Thus the default input representation is
\[
  x_0 = \RMSNorm(E[x]).
\]
If BigramHash is enabled, the input becomes
\[
  x_0=\RMSNorm(E[x]+\operatorname{BigramHashEmb}(x)).
\]

For a tensor $a\in\R^{B\times T\times D}$,
\[
  \RMSUnit(a) = \frac{a}{\sqrt{D^{-1}\sum_{i=1}^D a_i^2+\epsilon}},
  \qquad \epsilon=10^{-6}.
\]
The learned RMSNorm used outside the block is
\[
  \RMSNorm(a;g)=\RMSUnit(a)\odot g,\qquad g\in\R^D.
\]
Inside the block, the shared state preconditioner is parameter-free:
\[
  h = \RMSUnit(z+x_0).
\]
Every learned scale that conditions a projection is owned by that projection.
No learned prenorm scale is shared by two distinct linear maps.

\begin{definition}[Fixed point]
For fixed input $x_0$, write the shared block as
$T_\theta(\cdot,x_0):\R^{B\times T\times D}\to\R^{B\times T\times D}$.
A tensor $z^\star$ is an equilibrium if
\[
  z^\star = T_\theta(z^\star,x_0).
\]
\end{definition}

\section{Backbone Map}
\label{sec:arch}

\subsection{Dense Router}
\label{sec:router}

The active router is dense: all experts process all tokens, and the router
forms continuous mixture weights.  For a normalized component input $h$, the
default linear scorer is
\[
  \ell(h) = W_s(h\odot g_s) + b_{\rm expert},
\]
where $g_s$ is the router score prenorm scale.  The gate is
\[
  q(h)=\sigma\!\left(W_g(h\odot g_g)+b_g\right),
\]
with a separate gate prenorm scale $g_g$.  The routed mass is
\begin{equation}
  p(h) = \softmax(\ell(h))\odot q(h).
  \label{eq:router}
\end{equation}
The product in \eqref{eq:router} is not renormalized, so
$\sum_e p_e(h)\le 1$.  This lets the model suppress the routed expert bank when
a token is near equilibrium.  Health metrics renormalize shares within each
routed component before checking balance; total routed mass is logged
separately.

The block uses one pooled router over $2R$ routed outputs, where $S$ is the
number of shared experts and $R=E-S$.  The first $R$ entries route attention
experts and the last $R$ route MLP experts.  The $S$ shared experts bypass the
router and are modulated by learned sigmoid gates.

\subsection{Independent Expert Computation}
\label{sec:experts}

Each attention expert owns a full MLA-style attention pipeline:
low-rank query projection with appended per-head gate logits, low-rank
KV compression, independent K/V decompression from the latent, independent
low-rank RoPE key projection, per-expert Q/K RMS scales, and independent
low-rank output projection.  Expert index is packed into the head dimension,
so all experts are evaluated by one SDPA call with grouped-query attention.

Each MLP expert is a SwiGLU-style low-rank bank:
\[
  r_e(h) = \silu(W^g_e(h\odot g^g_e))\odot W^f_e(h\odot g^f_e),
\]
\[
  M_e(h)= W^o_e\!\left(\RMSUnit(r_e(h))\odot g^o_e\right).
\]
All expert-path trainable parameters are per-expert.  Shared trainable
parameters are allowed only for routing to experts, shared-expert gates, and
non-expert modules such as embedding and output heads.

\subsection{Block Equation}
\label{sec:block}

Let $A_e(h)$ and $M_e(h)$ denote the attention and MLP expert outputs.  Let
$p^A_r(h)$ and $p^M_r(h)$ be the routed weights from the pooled router, and let
$s^A_j(h)$ and $s^M_j(h)$ be the independent shared-expert gates for attention
and MLP.  The expert update is
\[
\begin{aligned}
  \Delta^A_\theta(z,x_0)
    &= \RMSNorm_A\!\left(
      \sum_{j=1}^{S} s^A_j(h) A_j(h)
      + \sum_{r=1}^{R} p^A_r(h) A_{S+r}(h)
    \right),\\
  \Delta^M_\theta(z,x_0)
    &= \RMSNorm_M\!\left(
      \sum_{j=1}^{S} s^M_j(h) M_j(h)
      + \sum_{r=1}^{R} p^M_r(h) M_{S+r}(h)
    \right),
\end{aligned}
\]
where $h=\RMSUnit(z+x_0)$.  The block update is
\[
  \Delta_\theta(z,x_0)=\Delta^A_\theta(z,x_0)+\Delta^M_\theta(z,x_0).
\]

The input-injection normalization uses the learned per-channel scale
$g_{x0}=\texttt{x0\_inject\_norm\_weight}$:
\[
  \RMSNorm_{x_0}(x_0)=\RMSUnit(x_0)\odot g_{x0}.
\]
The current fixed-point map is
\begin{equation}
  T_\theta(z,x_0;\bar B)
    = \bar B \odot \RMSNorm_{x_0}(x_0)
      + \Delta_\theta(z,x_0),
  \label{eq:Tx_new}
\end{equation}
The learned scale makes the input-injection norm learnable, while the RMS
denominator is parameter-free.  The input affects the map twice: structurally
through $h=\RMSUnit(z+x_0)$ and explicitly through the Parcae input-gain term.
There is no unconditional residual of the form $x_0+\Delta_\theta$.

When \texttt{Block.forward} is called directly with no \texttt{b\_bar}, code
uses the unit fallback $\bar B=\mathbf{1}$ for tests.  In the solver path,
$\bar B$ is always passed explicitly through the RevDEQ custom autograd
boundary.

\section{Parcae and RevDEQ}
\label{sec:algorithm}

\subsection{Parcae Coefficients}
\label{sec:parcae_params}

The raw Parcae parameters produce positive step, decay, and input-gain
magnitudes.  With $\epsilon_{\min}=10^{-3}$,
\[
  \delta = \operatorname{softplus}(r_\delta)+\epsilon_{\min},
  \qquad
  a = \operatorname{softplus}(r_a)+\epsilon_{\min},
  \qquad
  b = \operatorname{softplus}(r_b)+\epsilon_{\min}.
\]
Let $\epsilon_{\rm rev}=\texttt{parcae\_reversibility\_floor}=0.1$.  The
solver retention, solver blend, and input gain are
\begin{equation}
  \bar A
    = \epsilon_{\rm rev}
      +(1-\epsilon_{\rm rev})\exp(-\delta\odot a),
  \qquad
  \beta = 1-\bar A,
  \qquad
  \bar B = \delta\odot b.
  \label{eq:parcae}
\end{equation}
Thus $\bar A\in(\epsilon_{\rm rev},1)$ and $\beta\in(0,1-\epsilon_{\rm rev})$.
The same $\delta$ appears in both $\bar A$ and $\bar B$, but $\bar A$ and
$\bar B$ otherwise encode different learnable effects: $\bar A$ controls
state retention in the solver and $\bar B$ controls explicit input forcing
inside $T_\theta$.

Initialization chooses $\delta_0=1$, $\bar A_0\approx0.7$, and
$\bar B_0\approx1-\bar A_0=0.3$.

\subsection{RevDEQ Forward Solve}
\label{sec:revdeq_forward}

For each DEQ solve, the forward pass initializes $y_0=z_0=x_0$ and applies
the coupled update
\begin{equation}
\begin{aligned}
  y_{k+1} &= \bar A\odot y_k
          + \beta\odot T_\theta(z_k,x_0;\bar B),\\
  z_{k+1} &= \bar A\odot z_k
          + \beta\odot T_\theta(y_{k+1},x_0;\bar B).
\end{aligned}
\label{eq:revdeq_forward}
\end{equation}
for $k=0,\ldots,K-1$.  At a common equilibrium $y^\star=z^\star$, the damping
cancels from \eqref{eq:revdeq_forward}:
\[
  z^\star = \bar A\odot z^\star
          + (1-\bar A)\odot T_\theta(z^\star,x_0;\bar B).
\]
Since $1-\bar A=\beta$ has positive entries, the equilibrium condition reduces
to the fixed-point equation
\[
  z^\star = T_\theta(z^\star,x_0;\bar B).
\]

The default training step samples the forward iteration count from
$K\in\{4,6,10\}$ using a shuffle-bag sampler.  Evaluation defaults to
$K=16$, and the final diagnostic sweep evaluates
$K\in\{4,8,16,32,64,128\}$ after int6 round-trip.

\subsection{Reversible Backward and Gradients}
\label{sec:revdeq_backward_combined}

The reversible backward pass starts from the terminal forward states and
reconstructs earlier states using the same equations in reverse.  With
$u_y=T_\theta(y_{k+1},x_0;\bar B)$, the preceding $z$ state is
\[
  z_k = \frac{z_{k+1}-\beta\odot u_y}{1-\beta}
      = \frac{z_{k+1}-\beta\odot u_y}{\bar A}.
\]
With $u_z=T_\theta(z_k,x_0;\bar B)$, the preceding $y$ state is
\[
  y_k = \frac{y_{k+1}-\beta\odot u_z}{\bar A}.
\]
The denominator is safe because $\bar A\ge\epsilon_{\rm rev}=0.1$ in every
dimension.  This lower bound is a correctness constant for reconstruction,
not a modeling hyperparameter.  No analogous floor is imposed on $\bar B$:
$\bar B$ affects $T_\theta$ but never appears as a divisor in the reverse
step.

Gradients reach all Parcae parameters through explicit solver inputs.  The
blend $\beta=1-\bar A$ carries gradients to $r_a$ and $r_\delta$ through the
coupled-state update.  The live input gain $\bar B=\delta\odot b$ carries
gradients to $r_b$ and $r_\delta$ through each re-evaluation of
$T_\theta(z,x_0;\bar B)$.  Hiding $\bar B$ as mutable module state would break
this chain; it must cross the custom-autograd boundary as an explicit tensor.

Default backward is truncated: each step samples
$K_{\rm bptt}\in\{2,3,4\}$.  Earlier forward iterations do not receive task
gradient when truncation is active.

\section{Head, Refinement, and Losses}
\label{sec:head}

After the final solve, the representation is
$h_{\rm out}=\RMSNorm(z^\star)$.  The output head is a low-rank
mixture-of-softmaxes (MoS) with two shared experts and one specialized expert.
For a flattened token representation $h_n$,
\[
  \alpha_n=\softmax(G(\RMSUnit(h_n)\odot g_G)),
\]
\[
  t_{n,e}=A_e^\top(\RMSUnit(h_n)\odot g^A_e),
  \qquad
  q_{n,e}=\operatorname{FSQ}(t_{n,e}).
\]
FSQ code exists, but the default is \texttt{fsq\_levels=0}, so
$q_{n,e}=t_{n,e}$.  The NTP distribution is
\[
  \log p_{\rm NTP}(w\mid h_n)
    = \log\sum_e \alpha_{n,e}
      \operatorname{softmax}(B_e q_{n,e})_w .
\]

The current default is NTP-only: \texttt{use\_ctp=False}.  CTP parameter banks
are not allocated; \texttt{MoSHead.forward} returns the NTP log-probabilities
for both API outputs, and \texttt{GPT.forward} sets the CTP loss weight to zero.
If \texttt{use\_ctp=True}, the older CTP head and CTP loss path remain
available for ablation.

Refinement is an outer loop around the DEQ solve.  It is disabled for the first
85\% of training by default.  Once enabled, the model predicts from $z^\star$,
forms a sparse top-$k$ soft embedding from shifted NTP probabilities, and
solves again with the refined input
\[
  x_0^{\rm new}
    = \alpha_{\rm ref}\, \operatorname{SoftEmbed}(z^\star)
      +(1-\alpha_{\rm ref})x_0^{\rm prev},
\]
where $\alpha_{\rm ref}$ ramps from $0$ to $0.5$.

The task-side training loss is
\[
\begin{aligned}
  \mathcal{L}_{\rm main}
    &= \mathcal{L}_{\rm NTP}
     + \lambda_{\rm bal}\mathcal{L}_{\rm router\_bal}
     + \lambda_{\rm health}\mathcal{L}_{\rm router\_health} \\
    &\quad
     + \lambda_{\rm mos}\mathcal{L}_{\rm mos\_ortho}
     + \lambda_{\rm block}\mathcal{L}_{\rm block\_ortho}.
\end{aligned}
\]
With default \texttt{use\_ctp=False}, no CTP task term contributes.

\section{Jacobian and Denoising Regularization}
\label{sec:regularization}\label{sec:reg}

The code stores $z^\star$ and the active $x_0$ detached after the DEQ solve.
On the final micro-step only, it adds two local-stability regularizers outside
the compiled model forward.  As noted in the abstract and Section~\ref{sec:summary},
both coefficients ($\lambda_J=\texttt{lyapunov\_coef}$,
$\lambda_D=\texttt{denoising\_coef}$) default to $0.0$ in the iter-89 baseline,
so neither penalty contributes to the training loss as configured; the rest of
this section describes the code path that activates when the coefficients are
set positive.

\paragraph{Hutchinson-Frobenius surrogate.}
Draw a Rademacher probe $v\in\{-1,+1\}^{B\times T\times D}$ and set
$z_b=\stopgrad(z^\star)$ with \texttt{requires\_grad=True}.  Compute
\[
  u_b = T_\theta(z_b,x_0;\stopgrad(\bar B)),
  \qquad
  q = \nabla_{z_b}\langle u_b,v\rangle
      = J(z_b)^\top v,
\]
where $J(z_b)=\nabla_z T_\theta(z_b,x_0;\bar B)$.  The sample estimate is
\[
  \hat\rho_{\rm sample}
    = \sqrt{\frac{1}{BTD}\|q\|_2^2}.
\]
The implementation keeps a GPU-resident EMA
\[
  \hat\rho \leftarrow 0.9\,\hat\rho + 0.1\,\hat\rho_{\rm sample}.
\]
The VJP path uses detached $\bar B$ so the probe is a diagnostic, not a
second-order learning signal.

The trainable first-order surrogate re-evaluates the block with live $\bar B$:
\[
  \hat v = \frac{q}{\|q\|_2+\epsilon},\qquad
  c = \stopgrad\left(\frac{(\hat\rho-\gamma)_+}{\max(\hat\rho,\epsilon)}\right),
\]
\begin{equation}
  \mathcal{L}_{\rm jac}
    = \lambda_{\rm jac}\,s(t)\,c\,
      \left|\left\langle
        T_\theta(\stopgrad(z^\star),x_0;\bar B),\hat v
      \right\rangle\right|.
  \label{eq:ljac}
\end{equation}
Here $\gamma=0.97$, $\lambda_{\rm jac}=0.01$, and $s(t)$ ramps linearly over
the first 5\% of training.  This avoids \texttt{create\_graph=True} and
\texttt{retain\_graph=True}; gradients reach $\theta$ and Parcae's live
$\bar B$ through the second block evaluation.

\paragraph{Finite-perturbation denoising.}
With $\xi\sim\mathcal{N}(0,\sigma^2I)$ and $\sigma=0.01$,
\[
  \mathcal{L}_{\rm denoise}
    = \lambda_{\rm denoise}\,s(t)\,
      \left\|
        T_\theta(\stopgrad(z^\star)+\xi,x_0;\bar B)-\stopgrad(z^\star)
      \right\|_2^2/(BTD),
\]
where $\lambda_{\rm denoise}=0.01$.  This regularizes finite perturbations
around the reached equilibrium and complements the infinitesimal Jacobian
surrogate.

The total loss used for backpropagation is
\[
  \mathcal{L}
    = \mathcal{L}_{\rm main}
    + \mathcal{L}_{\rm jac}
    + \mathcal{L}_{\rm denoise}.
\]

\section{Quantization and Validation}
\label{sec:validation}

After training, the script serializes the current code and model state.  Matrix,
embedding, and optional BigramHash tensors are quantized by per-row int6
helpers and compressed with zstd level 22.  The required budget is
\[
  \texttt{len(code bytes)}+\texttt{len(compressed model bytes)}
  \le 16{,}000{,}000.
\]
The model is then dequantized, loaded back into the same architecture, and
validated after round-trip.

The fixed-point diagnostic sweep evaluates the quantized model at
\[
  K\in\{4,8,16,32,64,128\}.
\]
The hard checks are intentionally coarse enough to avoid treating finite-$K$
noise as failure:
\begin{itemize}[leftmargin=2em,itemsep=0.2em]
  \item gross degradation: the worst $K\ge 16$ bpb must be within 0.1 of the
        best sweep bpb;
  \item deep-$K$ non-degradation: $K=64$ and $K=128$ must be within 0.02 of
        the best sweep bpb;
  \item relative iterate convergence at the highest evaluated $K$ must be
        at most 0.1;
  \item RevDEQ reconstruction error must be at most 0.1;
  \item routed expert usage and expert orthogonality must pass the post-int6
        health gates.
\end{itemize}

\section{Local Stability Guarantee}
\label{sec:lyapunov}

This section states the mathematical guarantee used to justify the local
stability target.  It is a property of the fixed-point map $T$, not a claim that
the current finite-step solver globally converges from every state.

\begin{definition}[Spectral radius]
For a square linear operator $A$,
\[
  \rho(A)=\max\{|\lambda|:\lambda \text{ is an eigenvalue of } A\}.
\]
\end{definition}

\begin{definition}[Local exponential stability]
Let $z^\star=T(z^\star)$ and define the iteration $z_{k+1}=T(z_k)$.  The fixed
point is locally exponentially stable if there exist $\delta>0$, $C>0$, and
$\eta\in(0,1)$ such that
\[
  \|z_0-z^\star\|<\delta
  \quad\Longrightarrow\quad
  \|z_k-z^\star\|\le C\eta^k\|z_0-z^\star\|
  \quad\text{for all }k\ge0.
\]
\end{definition}

\begin{theorem}[Jacobian spectral radius below one implies local convergence]
\label{thm:lyap_main}
Let $T$ be continuously differentiable in a neighborhood of $z^\star$, and let
$z^\star=T(z^\star)$.  If
\[
  \rho\!\left(\nabla T(z^\star)\right)<1,
\]
then $z^\star$ is locally exponentially stable for $z_{k+1}=T(z_k)$.
\end{theorem}

\begin{proof}
Let $J=\nabla T(z^\star)$.  Since $\rho(J)<1$, the discrete Lyapunov theorem
implies that for any $Q\succ0$ there is a unique $P\succ0$ solving
\[
  J^\top P J-P=-Q.
\]
Equivalently, one may take the convergent series
\[
  P=\sum_{i=0}^{\infty}(J^\top)^i QJ^i .
\]
For the linearized error system $e_{k+1}=Je_k$, the quadratic function
$V(e)=e^\top Pe$ satisfies
\[
  V(Je)-V(e)=e^\top(J^\top PJ-P)e=-e^\top Qe.
\]
Thus the linearized system is exponentially stable.

For the nonlinear map, differentiability gives
\[
  T(z^\star+e)-z^\star = Je+r(e),
  \qquad
  \|r(e)\|=o(\|e\|).
\]
Choose a neighborhood where $\|r(e)\|\le\varepsilon\|e\|$.  Then
\[
\begin{aligned}
  V(Je+r)-V(e)
    &= -e^\top Qe + 2e^\top J^\top Pr + r^\top Pr \\
    &\le -\lambda_{\min}(Q)\|e\|^2
      +2\|J^\top P\|\varepsilon\|e\|^2
      +\|P\|\varepsilon^2\|e\|^2 .
\end{aligned}
\]
Taking $\varepsilon$ small enough makes the last two terms at most
$\frac12\lambda_{\min}(Q)\|e\|^2$.  Hence $V$ strictly decreases in a
neighborhood of $z^\star$, which implies local exponential stability.
\end{proof}

\begin{remark}[What the theorem does and does not say]
The condition is local and pointwise at the reached equilibrium.  It does not
give global uniqueness, global convergence, or a guarantee that arbitrary
initializations land in the same basin.  It justifies training pressure that
shrinks the local Jacobian around solver-reached states.  The code's K-sweep,
iterate-convergence, and reconstruction checks are the empirical validation
that the finite RevDEQ/Parcae solver behaves like a useful fixed-point model.
\end{remark}
