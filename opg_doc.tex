\begin{abstract}
This document describes the current \texttt{train\_gpt.py} implementation.
The model is a small language model for the Parameter Golf setting: the final
artifact is code plus compressed weights, capped at 16,000,000 bytes, and
evaluated by validation bits per byte.  The active backbone is a reversible
deep-equilibrium (RevDEQ) solve over one shared transformer-like block.  The
block uses dense soft routing over fully independent attention and MLP expert
banks, Parcae per-dimension damping and input gain, an NTP-only
mixture-of-softmaxes output head by default, a flattened routing/diversity
regularization stack, int6 round-trip quantization, and post-training
fixed-point diagnostics.

The stability objective is local, not global: the code does not enforce a
global Banach contraction with ball projections or spectral-normalization caps.
The Jacobian-spectral-radius and finite-perturbation denoising regularizers
described in Section~\ref{sec:reg} (with coefficients
$\lambda_J=\texttt{lyapunov\_coef}$, $\lambda_D=\texttt{denoising\_coef}$) are
\emph{disabled by default} (both coefficients are $0.0$); empirically the
Parcae per-dimension $\bar A$ already provides the useful local damping signal.
The terms remain in code so they can be re-enabled without an architectural
change.  The theorem in Section~\ref{sec:lyapunov} records the self-contained
mathematical guarantee: if the Jacobian of the fixed-point map has spectral
radius below one at an equilibrium, that equilibrium is a local exponentially
stable attractor.
\end{abstract}

\section{Summary}
\label{sec:summary}

For token IDs $x\in\{0,\ldots,V-1\}^{B\times T}$, the model first builds an
input state $x_0\in\R^{B\times T\times D}$ from token embeddings and then
solves one shared block to equilibrium.  BigramHash is disabled by default, so
$x_0=\RMSNorm(E[x])$ in the default run.  For any tensor
$u\in\R^{B\times T\times D}$, define
\[
  \RMSUnit(u)
    = \frac{u}{\sqrt{D^{-1}\sum_{i=1}^D u_i^2+\epsilon}},
  \qquad
  \RMSNorm_{x_0}(x_0)=\RMSUnit(x_0)\odot g_{x0}.
\]
Here $g_{x0}$ is the learned per-channel scale
\texttt{x0\_inject\_norm\_weight}; it makes the input-injection normalization
learnable, while the RMS denominator remains parameter-free.

The shared block forms a dense-expert attention-plus-MLP update
$\Delta_\theta(z,x_0)$ using the parameter-free preconditioner
$h=\RMSUnit(z+x_0)$.  Parcae supplies per-channel retention, solver blend, and
input gain
\[
  \bar A=\epsilon_{\rm rev}+(1-\epsilon_{\rm rev})\exp(-\delta\odot a),
  \qquad
  \beta=1-\bar A,
  \qquad
  \bar B=\delta\odot b,
\]
with positive $\delta,a,b$ and $\epsilon_{\rm rev}=0.1$.  The fixed-point map is
\[
  T_\theta(z,x_0;\bar B)
    = \bar B\odot\RMSNorm_{x_0}(x_0)+\Delta_\theta(z,x_0).
\]
Thus $x_0$ conditions the block through both $h$ and the explicit
input-gain term; there is no unconditional residual $x_0+\Delta_\theta$.

RevDEQ iterates two states from $y_0=z_0=x_0$:
\[
\begin{aligned}
  y_{k+1} &= \bar A\odot y_k
          + \beta\odot T_\theta(z_k,x_0;\bar B),\\
  z_{k+1} &= \bar A\odot z_k
          + \beta\odot T_\theta(y_{k+1},x_0;\bar B).
\end{aligned}
\]
At a common equilibrium $y^\star=z^\star$, this reduces to
$z^\star=T_\theta(z^\star,x_0;\bar B)$.  The reversible backward pass
reconstructs earlier states by
\[
  z_k=\frac{z_{k+1}-\beta\odot T_\theta(y_{k+1},x_0;\bar B)}{\bar A},
  \qquad
  y_k=\frac{y_{k+1}-\beta\odot T_\theta(z_k,x_0;\bar B)}{\bar A}.
\]
The floor on $\bar A$ is required because $\bar A$ is the reverse denominator;
$\bar B$ is not floored because it is only an input gain inside
$T_\theta$.

The output head maps $h_{\rm out}=\RMSNorm(z^\star)$ to logits, with an
NTP-only mixture-of-softmaxes head by default.  The active training objective
is the NTP loss plus a flat router/diversity stack.  CTP, Jacobian, and
denoising terms are present as ablation paths gated by both a feature flag
(\texttt{use\_ctp}, etc.) and a coefficient (\texttt{ctp\_weight},
\texttt{lyapunov\_coef}, \texttt{denoising\_coef}); all flags default off and
all coefficients default zero.  After training, validation checks the int6 round-trip
artifact and a fixed-point iteration-count sweep.  The stability guarantee
applies to whichever map drives the iteration: under Parcae the active
solver iterates the joint two-state cycle
$F(y,z)=(\bar A y+\beta T_\theta(z),\bar A z+\beta T_\theta(\bar A y+\beta T_\theta(z)))$
with $\beta=1-\bar A$, so the relevant local condition is
$\rho(\nabla F(z^\star,z^\star))<1$ — a sufficient (not necessary)
spectral-radius condition for local exponential stability of the joint
iteration.  $T_\theta$ alone is retained as a decomposition diagnostic;
$\rho(\nabla T_\theta)<1$ is sufficient but not necessary for the joint
condition (Section~\ref{sec:lyapunov}, Remark~\ref{rem:contraction-objects}).

\subsection{Optimizer}
\label{sec:optimizer}

Matrix parameters use Muon with Polar-Express Newton--Schulz (PE-NS,
\texttt{use\_polar\_express\_ns=true} default, \texttt{muon\_backend\_steps=7}).
PE-NS uses minimax-tuned per-iteration polynomial coefficients that converge to
the matrix sign function faster than the stock Schulz-3 iteration; with 7
iterations this reaches the same tolerance as $\sim 12$ stock iterations,
giving slightly tighter orthogonalization at the same wall-clock cost.  Scalar
parameters use Adam ($\beta_1{=}0.85$, $\beta_2{=}0.90$); tied embeddings use
Adam at \texttt{tied\_embed\_lr=0.03}; Parcae raw parameters use a dedicated
\texttt{parcae\_lr=0.002}; the entmax blend logit (when entmax routing is
enabled) uses \texttt{entmax\_blend\_lr=0.002}.  Gradient clipping is applied
at norm $1.0$.

\paragraph{Practical implementation: PE-NS variance-regularizer interaction.}
The PE-NS default was briefly disabled in early iter 121 after iter 117 v2
NaN'd at step 30.  Bisection in iter 117 v3 identified the actual NaN driver
as the variance regularizer
$\mathcal{L}_{\mathrm{var}} = -\lambda \sum_e \mathrm{Var}_t(w(e \mid t))$
(introduced in H83) interacting with entmax-1.5: entmax produces exact-zero
routing weights above its threshold, and the negative-coefficient variance
term rewards larger token specialization, creating a positive feedback loop
that PE-NS's larger update spectrum amplifies.  Removing $\mathcal{L}_{\mathrm{var}}$
breaks the cascade; PE-NS @ 7 is then numerically stable and is the current
default since iter 117 v5 (PROMOTED 2026-04-30).  Code keeps both NS variants
behind \texttt{use\_polar\_express\_ns} for clean A/B comparison.

\section{Notation}
\label{sec:notation}

Let $B$ be batch size, $T$ sequence length, $D$ model width, and $V$ vocabulary
size.  Token IDs and next-token targets are
\[
  x,y \in \{0,\ldots,V-1\}^{B\times T}.
\]
The token embedding is $E[x]\in\R^{B\times T\times D}$.  BigramHash is present
in code but disabled by default.  Thus the default input representation is
\[
  x_0 = \RMSNorm(E[x]).
\]
If BigramHash is enabled, the input becomes
\[
  x_0=\RMSNorm(E[x]+\operatorname{BigramHashEmb}(x)).
\]

For a tensor $a\in\R^{B\times T\times D}$,
\[
  \RMSUnit(a) = \frac{a}{\sqrt{D^{-1}\sum_{i=1}^D a_i^2+\epsilon}},
  \qquad \epsilon=10^{-6}.
\]
The learned RMSNorm used outside the block is
\[
  \RMSNorm(a;g)=\RMSUnit(a)\odot g,\qquad g\in\R^D.
\]
Inside the block, the shared state preconditioner is parameter-free:
\[
  h = \RMSUnit(z+x_0).
\]
Every learned scale that conditions a projection is owned by that projection.
No learned prenorm scale is shared by two distinct linear maps.

\begin{definition}[Fixed point]
For fixed input $x_0$, write the shared block as
$T_\theta(\cdot,x_0):\R^{B\times T\times D}\to\R^{B\times T\times D}$.
A tensor $z^\star$ is an equilibrium if
\[
  z^\star = T_\theta(z^\star,x_0).
\]
\end{definition}

\section{Backbone Map}
\label{sec:arch}

\subsection{Dense Router}
\label{sec:router}

The active router is dense: all experts process all tokens, and the router
forms continuous mixture weights.  For a normalized component input $h$, the
default linear scorer is
\[
  \ell(h) = W_s(h\odot g_s) + b_{\rm expert},
\]
where $g_s$ is the router score prenorm scale.  The gate is
\[
  q(h)=\sigma\!\left(W_g(h\odot g_g)+b_g\right),
\]
with a separate gate prenorm scale $g_g$.  The routed mass is
\begin{equation}
  p(h) = \softmax(\ell(h))\odot q(h).
  \label{eq:router}
\end{equation}
The product in \eqref{eq:router} is not renormalized, so
$\sum_e p_e(h)\le 1$.  This lets the model suppress the routed expert bank when
a token is near equilibrium.  Health metrics renormalize shares within each
routed component before checking balance; total routed mass is logged
separately.

\paragraph{Current implementation.} As of the current CUDA/H100 training path
(2026-05-08, see
\texttt{experiments/docs/hypotheses.md}), the implementation defaults run a
Dirichlet-UCB scorer with the routed sigmoid gate disabled.  Per token,
$\alpha = \softplus(\ell(h)) + 1$ defines a Dirichlet posterior with mean
$\mu = \alpha / \sum \alpha$ and per-expert standard deviation
$\sigma_e = \sqrt{\alpha_e(\sum\alpha - \alpha_e) / ((\sum\alpha)^2(\sum\alpha+1))}$;
routing weights are $p(h) = \mathrm{acq} / \sum \mathrm{acq}$ where
$\mathrm{acq} = \mu + \beta \sigma$ and $\beta=0.5$ anneals to zero over
training.  With \texttt{use\_router\_sigmoid\_gate=False} the
$\sum_e p_e(h)\le 1$ suppress-bank capability is also off — total routed mass
is exactly $1$ at every token.  The CV regularizer
(\texttt{router\_load\_cv\_coef}) is replaced by EMA-anchored balance and
specialization terms plus a small strict alive hinge with a straight-through
current-routing anchor (see the loss section).  Treat
\texttt{train\_gpt.py::Hyperparameters} as authoritative if this mirror drifts.

The block uses one pooled router over $2R$ routed outputs, where $S$ is the
number of shared experts and $R=E-S$.  The first $R$ entries route attention
experts and the last $R$ route MLP experts.  In the iter146 rescue stack
default ($S=0$, no routed sigmoid gate), every expert is routed and routed
mass is always applied; if a future ablation re-enables shared experts,
the $S$ always-on experts bypass the router and are independently modulated
(legacy sigmoid gates, default off).

\subsection{Independent Expert Computation}
\label{sec:experts}

Each attention expert owns a full MLA-style attention pipeline:
low-rank query projection with appended per-head gate logits, low-rank
KV compression, independent K/V decompression from the latent, independent
low-rank RoPE key projection, per-expert Q/K RMS scales, and independent
low-rank output projection.  Expert index is packed into the head dimension,
so all experts are evaluated by one SDPA call with grouped-query attention.

Each MLP expert is a SwiGLU-style low-rank bank:
\[
  r_e(h) = \silu(W^g_e(h\odot g^g_e))\odot W^f_e(h\odot g^f_e),
\]
\[
  M_e(h)= W^o_e\!\left(\RMSUnit(r_e(h))\odot g^o_e\right).
\]
All expert-path trainable parameters are per-expert.  Shared trainable
parameters are allowed only for routing to experts, shared-expert gates, and
non-expert modules such as embedding and output heads.

\subsection{Block Equation}
\label{sec:block}

Let $A_e(h)$ and $M_e(h)$ denote the attention and MLP expert outputs.  Let
$p^A_r(h)$ and $p^M_r(h)$ be the routed weights from the pooled router, and let
$s^A_j(h)$ and $s^M_j(h)$ be the independent shared-expert gates for attention
and MLP.  The expert update is
\[
\begin{aligned}
  \Delta^A_\theta(z,x_0)
    &= \RMSNorm_A\!\left(
      \sum_{j=1}^{S} s^A_j(h) A_j(h)
      + \sum_{r=1}^{R} p^A_r(h) A_{S+r}(h)
    \right),\\
  \Delta^M_\theta(z,x_0)
    &= \RMSNorm_M\!\left(
      \sum_{j=1}^{S} s^M_j(h) M_j(h)
      + \sum_{r=1}^{R} p^M_r(h) M_{S+r}(h)
    \right),
\end{aligned}
\]
where $h=\RMSUnit(z+x_0)$.  The block update is
\[
  \Delta_\theta(z,x_0)=\Delta^A_\theta(z,x_0)+\Delta^M_\theta(z,x_0).
\]

The input-injection normalization uses the learned per-channel scale
$g_{x0}=\texttt{x0\_inject\_norm\_weight}$:
\[
  \RMSNorm_{x_0}(x_0)=\RMSUnit(x_0)\odot g_{x0}.
\]
The current fixed-point map is
\begin{equation}
  T_\theta(z,x_0;\bar B)
    = \bar B \odot \RMSNorm_{x_0}(x_0)
      + \Delta_\theta(z,x_0),
  \label{eq:Tx_new}
\end{equation}
The learned scale makes the input-injection norm learnable, while the RMS
denominator is parameter-free.  The input affects the map twice: structurally
through $h=\RMSUnit(z+x_0)$ and explicitly through the Parcae input-gain term.
There is no unconditional residual of the form $x_0+\Delta_\theta$.

When \texttt{Block.forward} is called directly with no \texttt{b\_bar}, code
uses the unit fallback $\bar B=\mathbf{1}$ for tests.  In the solver path,
$\bar B$ is always passed explicitly through the RevDEQ custom autograd
boundary.

\section{Parcae and RevDEQ}
\label{sec:algorithm}

\subsection{Parcae Coefficients}
\label{sec:parcae_params}

The raw Parcae parameters produce positive step, decay, and input-gain
magnitudes.  With $\epsilon_{\min}=10^{-3}$,
\[
  \delta = \operatorname{softplus}(r_\delta)+\epsilon_{\min},
  \qquad
  a = \operatorname{softplus}(r_a)+\epsilon_{\min},
  \qquad
  b = \operatorname{softplus}(r_b)+\epsilon_{\min}.
\]
Let $\epsilon_{\rm rev}=\texttt{parcae\_reversibility\_floor}=0.1$.  The
solver retention, solver blend, and input gain are
\begin{equation}
  \bar A
    = \epsilon_{\rm rev}
      +(1-\epsilon_{\rm rev})\exp(-\delta\odot a),
  \qquad
  \beta = 1-\bar A,
  \qquad
  \bar B = \delta\odot b.
  \label{eq:parcae}
\end{equation}
Thus $\bar A\in(\epsilon_{\rm rev},1)$ and $\beta\in(0,1-\epsilon_{\rm rev})$.
The same $\delta$ appears in both $\bar A$ and $\bar B$, but $\bar A$ and
$\bar B$ otherwise encode different learnable effects: $\bar A$ controls
state retention in the solver and $\bar B$ controls explicit input forcing
inside $T_\theta$.

Initialization chooses $\delta_0=1$, $\bar A_0\approx0.7$, and
$\bar B_0\approx1-\bar A_0=0.3$.

\subsection{RevDEQ Forward Solve}
\label{sec:revdeq_forward}

For each DEQ solve, the forward pass initializes $y_0=z_0=x_0$ and applies
the coupled update
\begin{equation}
\begin{aligned}
  y_{k+1} &= \bar A\odot y_k
          + \beta\odot T_\theta(z_k,x_0;\bar B),\\
  z_{k+1} &= \bar A\odot z_k
          + \beta\odot T_\theta(y_{k+1},x_0;\bar B).
\end{aligned}
\label{eq:revdeq_forward}
\end{equation}
for $k=0,\ldots,K-1$.  At a common equilibrium $y^\star=z^\star$, the damping
cancels from \eqref{eq:revdeq_forward}:
\[
  z^\star = \bar A\odot z^\star
          + (1-\bar A)\odot T_\theta(z^\star,x_0;\bar B).
\]
Since $1-\bar A=\beta$ has positive entries, the equilibrium condition reduces
to the fixed-point equation
\[
  z^\star = T_\theta(z^\star,x_0;\bar B).
\]

The default training step samples the forward iteration count from
$K\in\{16,24,32,64,96,128\}$ using a deterministic weighted bag with weights
$(0.50,0.40,0.07,0.03,0.015,0.0075)$ (low-frequency tail at K=96 and
K=128 added 2026-05-13 to expose training to the gate-relevant K=128
evaluation depth).  Evaluation defaults to
$K=16$, and the final diagnostic sweep evaluates
\[
  K\in\{4,8,16,17,24,32,37,64,113,128\}
\]
after int6 round-trip.  The prime values $17$, $37$, and $113$ are acyclicity
checks: a stable fixed point should not show special behavior only at powers
of two or multiples of the training jitter values.

\subsection{Reversible Backward and Gradients}
\label{sec:revdeq_backward_combined}

The reversible backward pass starts from the terminal forward states and
reconstructs earlier states using the same equations in reverse.  With
$u_y=T_\theta(y_{k+1},x_0;\bar B)$, the preceding $z$ state is
\[
  z_k = \frac{z_{k+1}-\beta\odot u_y}{1-\beta}
      = \frac{z_{k+1}-\beta\odot u_y}{\bar A}.
\]
With $u_z=T_\theta(z_k,x_0;\bar B)$, the preceding $y$ state is
\[
  y_k = \frac{y_{k+1}-\beta\odot u_z}{\bar A}.
\]
The denominator is safe because $\bar A\ge\epsilon_{\rm rev}=0.1$ in every
dimension.  This lower bound is a correctness constant for reconstruction,
not a modeling hyperparameter.  No analogous floor is imposed on $\bar B$:
$\bar B$ affects $T_\theta$ but never appears as a divisor in the reverse
step.

Gradients reach all Parcae parameters through explicit solver inputs.  The
blend $\beta=1-\bar A$ carries gradients to $r_a$ and $r_\delta$ through the
coupled-state update.  The live input gain $\bar B=\delta\odot b$ carries
gradients to $r_b$ and $r_\delta$ through each re-evaluation of
$T_\theta(z,x_0;\bar B)$.  Hiding $\bar B$ as mutable module state would break
this chain; it must cross the custom-autograd boundary as an explicit tensor.

Default backward is truncated to the last $K_{\rm bptt}=3$ forward
iterations.  Earlier forward iterations do not receive task gradient when
truncation is active.  The old stochastic TBPTT sampler remains in the
configuration surface, but \texttt{deq\_bptt\_k\_jitter=false} by default to
avoid multiplying the compile-cache axis by the forward K-jitter axis.

\section{Head, Refinement, and Losses}
\label{sec:head}

After the final solve, the representation is
$h_{\rm out}=\RMSNorm(z^\star)$.  The output head is a low-rank
mixture-of-softmaxes (MoS) with two shared experts and one specialized expert.
For a flattened token representation $h_n$,
\[
  \alpha_n=\softmax(G(\RMSUnit(h_n)\odot g_G)),
\]
\[
  t_{n,e}=A_e^\top(\RMSUnit(h_n)\odot g^A_e),
  \qquad
  q_{n,e}=\operatorname{FSQ}(t_{n,e}).
\]
FSQ code exists, but the default is \texttt{fsq\_levels=0}, so
$q_{n,e}=t_{n,e}$.  The NTP distribution is
\[
  \log p_{\rm NTP}(w\mid h_n)
    = \log\sum_e \alpha_{n,e}
      \operatorname{softmax}(B_e q_{n,e})_w .
\]

The current default is NTP-only: \texttt{use\_ctp=False}.  CTP parameter banks
are not allocated; \texttt{MoSHead.forward} returns the NTP log-probabilities
for both API outputs, and \texttt{GPT.forward} sets the CTP loss weight to zero.
If \texttt{use\_ctp=True}, the older CTP head and CTP loss path remain
available for ablation.

\paragraph{Practical implementation: logit softcap (iter 122 / H93).}  When
\texttt{logit\_softcap} $>0$, per-expert logits are reshaped through a tanh
saturation \emph{before} the per-expert log-softmax,
\[
  \tilde\ell_{n,e,w}
    = c\,\tanh(\ell_{n,e,w}/c),\qquad c=\texttt{logit\_softcap},
\]
which bounds extreme logit magnitudes (Gemma2-style) and damps gradient
spikes without altering the convex log-softmax mixture identity.  Strict
generalization holds at $c=0$ (no-op short-circuit); records use $c=30$.

\paragraph{Practical implementation: conditional prefix-$K$ multi-anchor
supervision (iter 152 / \texttt{deq\_prefix\_anchors}).}
When \texttt{deq\_prefix\_anchors=True}, the forward DEQ solve still draws a
single sampled depth $K\sim\operatorname{Cat}(\texttt{deq\_k\_jitter\_set},
\texttt{deq\_k\_jitter\_weights})$, but the task-side cross-entropy is
averaged over every traversed prefix anchor $K_a$ that lies on the same
solve trajectory,
\[
  \mathcal{L}_{\rm NTP}^{\rm prefix}
    = \frac{1}{|\mathcal{A}(K)|}
      \sum_{K_a\in\mathcal{A}(K)}
        \mathbb{E}_n\bigl[-\log p_{\rm NTP}(y_n\mid h_n(K_a))\bigr],
  \quad
  \mathcal{A}(K)=\{K_a\in\texttt{deq\_k\_jitter\_set}: 0<K_a\le K\}\cup\{K\}.
\]
The forward budget is unchanged because $K_a<K$ anchors are captured as
intermediate states inside the same $K$-step solve, not as separate forward
passes.  MoS-side regularizers (MoS-CV, MoS diversity, and expert-output
diversity) attach to the \emph{final-endpoint} re-call of the output head, so
they target the fixed-point representation rather than its early-iteration
prefix.  Router-side regularizers (load CV, EMA balance, per-token entropy,
alive hinge) are populated during the solve itself and therefore aggregate
over the full trajectory in either mode; the prefix variant does not alter
their attachment.  Default is \texttt{deq\_prefix\_anchors=False}; iter 152
promoted the path on validation BPB (1.4718 vs 1.4787; see
\texttt{experiments/docs/hypotheses.md} for current numbers) but left
soft-diagnostic debt on \texttt{lip\_ub} and \texttt{attn\_min\_share}.

Refinement is an optional outer loop around the DEQ solve.  It is disabled by
default because \texttt{num\_refinements=0}; the 85\% ramp only matters when a
future run explicitly re-enables refinements.  Once enabled, the model predicts
from $z^\star$, forms a sparse top-$k$ soft embedding from shifted NTP
probabilities, and solves again with the refined input
\[
  x_0^{\rm new}
    = \alpha_{\rm ref}\, \operatorname{SoftEmbed}(z^\star)
      +(1-\alpha_{\rm ref})x_0^{\rm prev},
\]
where $\alpha_{\rm ref}$ ramps from $0$ to $0.5$.

The task-side training loss is now a flat coefficient stack:
\[
  \mathcal{L}_{\rm task}
    = \mathcal{L}_{\rm NTP}
    + \lambda_{\rm CTP}\mathcal{L}_{\rm CTP}
    + \mathcal{L}_{\rm router}.
\]
With default \texttt{use\_ctp=False} and \texttt{ctp\_weight=0.0}, no CTP
task term contributes.  The router/diversity term is
\[
\begin{aligned}
  \mathcal{L}_{\rm router}
    &= \lambda_{\rm rcv}\sum_{r\in\{\mathrm{attn},\mathrm{mlp}\}}
       \operatorname{CV}(m_r)^2 \\
    &\quad
     + \lambda_{\rm ent}(t)\sum_r H_{\rm pertoken}(m_r)
     + \lambda_{\rm mcv}\operatorname{CV}(m_{\rm MoS})^2 \\
    &\quad
     + \lambda_{\rm div}(t)\mathcal{D}_{\rm experts}
     + \lambda_{\rm mosdiv}(t)\mathcal{D}_{\rm MoS}.
\end{aligned}
\]
Here $m_r$ is the combined routed mass
\[
  m_r = \operatorname{route\_prob}_r(z,x_0)
\]
i.e. the dense token-local routing probability.  The optional learned sigmoid
router gate is default-off; when explicitly enabled, it multiplicatively
scales this mass and is included in the same diagnostics/losses.  CV penalties
use unbounded quadratic pressure (no target threshold), so
the term keeps pushing $\operatorname{CV}\to0$ even when balance is already
acceptable; this replaces the earlier hinge form $[\operatorname{CV}-\tau]_+^2$
which went silent below a fixed target.  The default expert diversity is scale-invariant cosine diversity; the Frobenius
variant remains a controlled ablation that bundles direction and norm pressure
into one term.

\paragraph{Implementation deviates from \S\ref{sec:experts} loss stack:
iter145r promoted defaults.} The iter145r promotion (2026-05-08) moves the
balance pressure off CV and onto an EMA-anchored stack.  Let
$\bar p_e$ be the per-router persistent EMA of expert usage (decay $0.99$,
detached, registered as a buffer so it survives checkpoint resume).  Define
the straight-through anchor $\tilde m = \mathrm{stopgrad}(\bar p) + (m - \mathrm{stopgrad}(m))$
which carries the forward value of the EMA but routes gradients through the
current step's routing mass $m$.  The promoted router term is
\[
\begin{aligned}
\mathcal{L}_{\rm router}^{\rm iter145r}
  &= \lambda_{\rm rcv}\sum_r \operatorname{CV}(m_r)^2
     + \lambda_{\rm ent}\sum_r H_{\rm pertoken}(m_r) \\
  &\quad + \lambda_{\rm bal}\sum_r \operatorname{KL}_{\rm bal}(r)
     + \lambda_{\rm alive}\sum_r (\bar d_r)\!\cdot\!(d_r)^2 \\
  &\quad - \lambda_{\rm spec}\sum_r \operatorname{KL}(p^{\rm token}_r\,\|\,\bar p_r) \\
  &\quad + \lambda_{\rm mcv}\operatorname{CV}(m_{\rm MoS})^2
     + \lambda_{\rm div}\mathcal{D}_{\rm experts}
     + \lambda_{\rm mosdiv}\mathcal{D}_{\rm MoS},
\end{aligned}
\]
where $U$ is the within-component uniform target,
$d_r = (\tau \cdot U - m_r)_+$ is the per-component deficit hinge with
$\tau=$\texttt{min\_share\_frac}, and $p^{\rm token}_r$ is the per-token share.
The balance divergence
$\operatorname{KL}_{\rm bal}(r) = \operatorname{KL}(U\,\|\,\tilde m_r)$
when \texttt{use\_reverse\_kl\_balance=True} (iter153 default; reverse KL
weights each expert by $U_i$, giving the dead-expert gradient $-U_i/\bar m_{r,i}$
that diverges as $\bar m_{r,i}\!\to\!0$).  Setting the flag to False recovers
the pre-iter153 form $\operatorname{KL}(\tilde m_r\,\|\,U)$, which weights each
term by $\tilde m_{r,i}$ so a dead expert's contribution vanishes despite a
large log-ratio.
The minus sign on the specialization term reflects KL maximization: minimizing
$-\lambda_{\rm spec}\,\mathrm{KL}$ pushes per-token routing AWAY from the
historical mean, bounded by $\log(E)$ since $\bar p$ is normalized and clamped.
Current coefficients: $\lambda_{\rm rcv}=0.0$ (CV off by default; remains
available),
$\lambda_{\rm bal}=0.30$, $\lambda_{\rm spec}=0.20$, $\lambda_{\rm alive}=0.02$,
$\lambda_{\rm ent}=0.1$, $\lambda_{\rm mcv}=0.15$, $\lambda_{\rm div}=0.30$,
$\lambda_{\rm mosdiv}=0.0$, with all coefficients ramped linearly over the
first \texttt{regularizer\_warmup\_frac=0.07} of training.  The
\texttt{use\_router\_sigmoid\_gate=False} default also means $m_r$ is the bare
softmax/Dirichlet-UCB output (no $\sigma(g)$ multiplier).  For the cosine
expert-output diversity path, $\mathcal{D}_{\rm experts}$ is the mean over
sampled tokens of the worst off-diagonal squared cosine pair, not the average
over all pairs.  \texttt{train\_gpt.py::Hyperparameters} and the
\texttt{ROUTER\_EMA\_LOSS\_TERMS} registry are authoritative on the EMA-family
sign convention.

\section{Jacobian and Denoising Regularization}
\label{sec:regularization}\label{sec:reg}

The code stores $z^\star$ and the active $x_0$ detached after the DEQ solve.
On the final micro-step only, it adds two local-stability regularizers outside
the compiled model forward.  As noted in the abstract and Section~\ref{sec:summary},
both coefficients ($\lambda_J=\texttt{lyapunov\_coef}$,
$\lambda_D=\texttt{denoising\_coef}$) default to $0.0$, so neither penalty
contributes to the training loss as configured; the rest of this section
describes the code path that activates when the coefficients are set positive.

\paragraph{Finite-expansion penalty.}
Draw a Gaussian perturbation direction $v$ on a small deterministic token
window and normalize it to RMS one, $\mathrm{rms}(\hat v)=1$.  With
$\epsilon=10^{-2}$, the configuration knob \texttt{lyapunov\_target} selects
which Jacobian the local expansion sample probes:
\begin{align*}
  M_T(z,x_0) &= T_\theta(z,x_0;\bar B) & \text{(\texttt{transition\_T}; iter147)} \\
  M_S(z,x_0) &= \bar A\cdot z + (1-\bar A)\cdot T_\theta(z,x_0;\bar B) & \text{(\texttt{iteration\_S}; advisory only)} \\
  M_F(y,z,x_0) &= \big(\bar A\cdot y + \beta\cdot T_\theta(z), \;\bar A\cdot z + \beta\cdot T_\theta(\bar A\cdot y + \beta\cdot T_\theta(z))\big) & \text{(\texttt{iteration\_F}; iter155 corrected)}
\end{align*}
where $\beta = 1-\bar A$.  The expansion sample is the directional derivative
of the chosen $M$ at the saved fixed point, RMS-normalized over the joint
output:
\[
  r =
  \frac{
    \operatorname{rms}\!\left(
      M(\stopgrad(z^\star)+\epsilon\hat v,x_0)
      -
      M(\stopgrad(z^\star),x_0)
    \right)
  }{\epsilon}.
\]
For \texttt{iteration\_F}, the joint state is $(y, z)$ initialized at
$(z^\star, z^\star)$ (since at the fixed point $y^\star = z^\star$ and
$T(z^\star) = z^\star$); independent random directions $\hat v_y, \hat v_z$
perturb each half, and $r$ is the joint RMS over both output halves.  The
penalty itself is unchanged:
\begin{equation}
  \mathcal{L}_{\rm jac}
    = \lambda_{\rm jac}\,s(t)\,(r-\gamma)_+^2.
  \label{eq:ljac}
\end{equation}
Here $\gamma=0.97$, and $s(t)$ is the same regularizer warmup scale used for
the router/diversity stack.  The penalty runs every
\texttt{lyapunov\_every=16} optimizer steps on at most
\texttt{lyapunov\_max\_tokens=64} tokens.  Cost: T and S branches share
two block evaluations; F branch needs four (the two-state cycle evaluates
$T$ twice).  Each branch is a soft directional proxy for the operator
norm of the chosen Jacobian (Hutchinson Frobenius$/\sqrt D$ on a single
random direction — an under-estimate of $\sigma_{\max}(J)$, not a
spectral-radius proxy).  The gate-aligned \emph{empirical local-contraction
metric} is \texttt{lip\_ub\_F} (estimate on the actual two-state Parcae
cycle), with \texttt{lip\_ub\_S} (single-state convex blend; advisory
surrogate) and \texttt{lip\_ub\_T} (transition map alone; decomposition
diagnostic) reported alongside for failure attribution.

\textbf{Honesty caveat.}  Power iteration with $n_\text{iters}=3$ in noisy
bf16 is a lower-bound estimator of $\sigma_{\max}$ — the reported
\texttt{lip\_ub\_F} systematically under-estimates the true operator
norm.  The safety multiplier (\texttt{fp\_lip\_ub\_safety}=1.10 by
default) is a heuristic conservative margin, not a proof.  Even
$\sigma_{\max}(J_F)<1$ exactly is only a sufficient condition for
$\rho(J_F)<1$ (a non-normal Jacobian can have $\rho \to 0$ while
$\sigma_{\max}$ stays large via "transient amplification"), so
\texttt{lip\_ub\_F} is best read as an \emph{empirical local-contraction
metric}, not a formal certificate.

\paragraph{Two tiers of contraction control.}
The codebase explicitly distinguishes two tiers of mechanism for the
contraction problem; conflating them is the source of overclaiming bugs
flagged in iter155 review:

\begin{enumerate}[leftmargin=2em,itemsep=0.2em]
  \item \emph{Architecture-agnostic empirical pressure} (current iter155
    + iter156a paths).  Mechanism: K-sweep \texttt{lip\_ub\_F} probe +
    Lyapunov-on-F soft FD penalty (with optional
    \texttt{lyapunov\_estimator=power\_jvp\_F} worst-direction probe) +
    iter156a heuristic Ā-projection governor.  Property: preserves model
    capacity (no Lipschitz constraint on the architecture itself), runs
    with default-off coefficient and BPB-gated aug-Lagrangian
    escalation.  Guarantee: \emph{none} — power iteration is a
    lower-bound estimator, the safety multiplier is heuristic, and the
    Ā governor is non-monotone in $\sigma_{\max}(J_F)$.  This tier
    measures and pressures the right object empirically.
  \item \emph{Formal-guarantee tier} (iter156b and siblings; not present
    in iter155).  Mechanisms with true upper-bound semantics:
    interval/explicit-Jacobian bound estimation over a local ball,
    spectral normalization of $\Delta$, bounded-Lipschitz block
    parameterization, or a learned $c\in(0,1]$ gain on $\Delta$ that is
    hard-projected at design time.  Property: introduces an explicit
    architectural Lipschitz constraint that may reduce model capacity in
    exchange for a real upper bound on $\sigma_{\max}(J_F)$.  Guarantee:
    a true Lipschitz cert is achievable only by combining a
    formal-tier mechanism with the F-side measurement.
\end{enumerate}

iter155 is firmly tier (1).  Promotion rules (BPB-gated, soft escalation)
reflect that.  No part of tier (1) should be described as a "certificate"
or as "guaranteeing" contraction or capacity preservation.  Moving to
tier (2) is an explicit model-class decision documented in iter156b.

The Banach-style FP error \emph{a posteriori bound metric} at the saved
fixed point uses the joint cycle residual paired with the same operator
norm: \texttt{fp\_bound = fp\_residual\_F / (1 - lip\_ub\_F)}, where
$\texttt{fp\_residual\_F} = \|F(z^\star,z^\star)-(z^\star,z^\star)\|_{\rm RMS}/\|(z^\star,z^\star)\|_{\rm RMS}$.
This is principled \emph{only if} \texttt{lip\_ub\_F} upper-bounds the
local Lipschitz constant on a neighborhood of $(z^\star, z^\star)$ — a
pointwise power-iteration estimate at the single sampled FP is an
\emph{empirical a posteriori bound metric}, not a formal Banach bound.
Producing a true Banach bound would require either an interval/explicit-
Jacobian estimate over a small local ball (e.g.\ Lipschitz-bound
estimation across a finite cover of perturbed $z$ samples) or a
hard Lipschitz-bound parameterization of $F$ (spectral-normalized layers,
bounded-Lipschitz blocks, or a learned $c\in(0,1]$ gain on $\Delta$
constrained at design time).  iter155 deliberately introduces neither;
\texttt{fp\_bound} is therefore reported as a comparable cross-iteration
metric, not a guarantee.

Gradients reach $\theta$ through the block evaluations under any target.
Under \texttt{iteration\_S} and \texttt{iteration\_F}, gradients
additionally reach Parcae's live $\bar A$ through the outside-linear-blend
coefficients (these are first-order, no second-order FD curvature concern,
so $\bar A$ is \emph{not} detached).  Parcae's $\bar B$, by contrast, is
\emph{detached} on the FD probe (\texttt{aux\_b\_bar.detach()}): $\bar B$
appears \emph{inside} the FD subtraction $\texttt{sb}(z+\epsilon u, x_0; \bar B)
- \texttt{sb}(z, x_0; \bar B)$, where its gradient would carry $O(\epsilon)$
second-order curvature noise.  $\bar B$ continues to receive task-side
gradients through the main forward and through the denoising path (when
enabled).  The coefficient $\lambda_{\rm jac}$ is the runtime value of
\texttt{lyapunov\_coef}; it remains $0.0$ by default.

The \texttt{iteration\_F} target is the right object for fixed-point
convergence: $F$ is the actual cycle the Parcae solver iterates (see
Section~\ref{sec:summary} and \texttt{RevDEQFunction.forward}'s alternating
$y$/$z$ update), so $\sigma_{\max}(\nabla F(z^\star, z^\star))<1$ is what
suffices for local exponential stability of the joint iteration in
Banach-norm sense (Theorem~\ref{thm:lyap_main} states the equivalent
spectral-radius condition for non-norm linearizations; the norm condition
is strictly stronger).  The earlier \texttt{transition\_T} and
\texttt{iteration\_S} targets are preserved as backward-compatible code
paths and as advisory diagnostics; their relations are documented in
Remark~\ref{rem:contraction-objects} below.

\paragraph{Finite-perturbation denoising.}
With $\xi\sim\mathcal{N}(0,\sigma^2I)$ and $\sigma=0.01$,
\[
  \mathcal{L}_{\rm denoise}
    = \lambda_{\rm denoise}\,s(t)\,
      \left\|
        T_\theta(\stopgrad(z^\star)+\xi,x_0;\bar B)-\stopgrad(z^\star)
      \right\|_2^2/(BTD),
\]
where $\lambda_{\rm denoise}$ is the runtime value of
\texttt{denoising\_coef}; it is $0.0$ by default.  This regularizes finite
perturbations around the reached equilibrium and complements the infinitesimal
Jacobian surrogate when explicitly enabled.

The total loss used for backpropagation is
\[
  \mathcal{L}
    = \mathcal{L}_{\rm task}
    + \mathcal{L}_{\rm jac}
    + \mathcal{L}_{\rm denoise}.
\]

\section{Quantization and Validation}
\label{sec:validation}

After training, the script serializes the current code and model state through
\texttt{encode\_scored\_artifact}.  Matrix tensors and optional BigramHash
tensors are quantized by per-row int6 helpers; token embeddings are
intentionally kept in fp16 by
\texttt{FP16\_KEEP\_PATTERNS=(\textquotedblleft tok\_emb\textquotedblright,)}
until an embedding-quantization ablation proves the BPB tradeoff.  The payload
is compressed with zstd level 22.  If
\texttt{use\_grouped\_artifact\_compression=True}, the grouped codec competes
behind the same byte-accounted interface and is accepted only when it is
strictly smaller than the baseline bytes; otherwise the baseline int6 artifact
is kept.  GPTQ/LQER remain rejected scaffolds until they are wired into this
scored codec interface.  The required budget is
\[
  \texttt{len(code bytes)}+\texttt{len(compressed model bytes)}
  \le 16{,}000{,}000.
\]
The model is then dequantized, loaded back into the same architecture, and
validated after round-trip.

The fixed-point diagnostic sweep is controlled by \texttt{eval\_profile}.
The default \texttt{diagnostic} profile evaluates
$K\in\{4,8,16,17,24,32,37,64,113,128\}$ and runs the local Lipschitz probe on
every row.  The \texttt{submission} profile evaluates
$K\in\{16,24,64,128\}$ and runs the Lipschitz probe only at $K=128$.
The \texttt{debug} profile evaluates only $K=16$ and probes only that row.
The hard checks are intentionally coarse enough to avoid treating finite-$K$
noise as failure:
\begin{itemize}[leftmargin=2em,itemsep=0.2em]
  \item gross degradation: the worst $K\ge 16$ bpb must be within 0.1 of the
        best sweep bpb;
  \item deep-$K$ non-degradation: $K=64$ and $K=128$ must be within 0.02 of
        the best sweep bpb;
  \item relative iterate convergence at the highest evaluated $K$ must be
        at most 0.1;
  \item RevDEQ reconstruction error must be at most 0.1;
  \item routed expert usage and expert orthogonality must pass the post-int6
        health gates.
\end{itemize}
Final metadata records both \texttt{score\_valid} and \texttt{health\_valid}.
With \texttt{diagnostic\_gate\_policy=advisory}, a full-validation BPB run can
remain \texttt{run\_valid=true} while health failures are recorded as
\texttt{validated\_with\_tech\_debt}.  With
\texttt{diagnostic\_gate\_policy=hard}, the same health failures produce
\texttt{run\_valid=false} and \texttt{status=health\_gate\_failed}.  Fast-only
final validation remains non-promotable regardless of health status.

\paragraph{Root-cause fix policy.}
Diagnostics identify failure modes; they do not automatically justify a new
metric-specific training loss.  Once the root cause is identified, the
preferred fix order is:
\begin{enumerate}[leftmargin=2em,itemsep=0.2em]
  \item architecture or parameterization that makes the bad state hard or
        impossible, such as bounded transition gains for contraction failures;
  \item a reusable controller or interface shared across components, such as
        the slow router-bias usage controller for routed min-share failures;
  \item a general regularizer tied to a model invariant, shared by every
        component that exposes that invariant;
  \item a metric-specific loss only as a temporary ablation, with an explicit
        exit plan.
\end{enumerate}
Every fix should state the invariant it enforces and which diagnostics merely
verify it.  For example, an attention min-share failure should first route to
the generic router usage controller, not to an attention-only min-share loss;
a \texttt{lip\_ub\_F} failure (the gate-aligned contraction object on the
actual two-state Parcae cycle map $F$) should first route to setting
\texttt{lyapunov\_target=iteration\_F} and tightening Parcae damping
\emph{together with} transition-map parameterization (since $J_F$ couples
$J_T$ through cross blocks $\beta\cdot J_T$ that damping alone cannot
suppress when $\sigma_{\max}(J_T)>1$), with \texttt{lip\_ub\_T} and
\texttt{lip\_ub\_S} consulted as decomposition diagnostics that attribute
the failure to damping-vs-transition causes; another coefficient sweep on
the same proxy Lyapunov loss without first switching the target is
forbidden.

\section{Local Stability Guarantee}
\label{sec:lyapunov}

This section states the mathematical guarantee used to justify the local
stability target.  It is stated generically for any iteration map $M$ —
under Parcae the active solver's iterated map is the joint two-state
$M = F$ (Remark~\ref{rem:contraction-objects}), not the transition map
$T_\theta$ in isolation.  The guarantee is local: it does not claim that
the current finite-step solver globally converges from every state.

\begin{definition}[Spectral radius]
For a square linear operator $A$,
\[
  \rho(A)=\max\{|\lambda|:\lambda \text{ is an eigenvalue of } A\}.
\]
\end{definition}

\begin{definition}[Local exponential stability]
Let $x^\star=M(x^\star)$ and define the iteration $x_{k+1}=M(x_k)$.  The
fixed point is locally exponentially stable if there exist $\delta>0$,
$C>0$, and $\eta\in(0,1)$ such that
\[
  \|x_0-x^\star\|<\delta
  \quad\Longrightarrow\quad
  \|x_k-x^\star\|\le C\eta^k\|x_0-x^\star\|
  \quad\text{for all }k\ge0.
\]
\end{definition}

\begin{theorem}[Jacobian spectral radius below one implies local convergence]
\label{thm:lyap_main}
Let $M$ be continuously differentiable in a neighborhood of $x^\star$,
and let $x^\star=M(x^\star)$.  If
\[
  \rho\!\left(\nabla M(x^\star)\right)<1,
\]
then $x^\star$ is locally exponentially stable for $x_{k+1}=M(x_k)$.
\end{theorem}

\paragraph{Application to the active solver.}
Under Parcae, the iterated map is $M=F$ on the joint state $(y, z)$;
the relevant local condition is therefore
$\rho(\nabla F(z^\star,z^\star))<1$.  The K-sweep estimator
\texttt{rho\_F} reports $\rho(\nabla F)$ via straight power iteration on
$J_F$ (\(v_{k+1}=J_F v_k/\|J_F v_k\|\); the per-step ratio
\(\|J_F v\|/\|v\|\) at convergence equals $|\lambda_{\max}|$).  This
is the gate-relevant signal because $\rho<1$ is necessary AND sufficient
for the local condition above.  An auxiliary K-sweep estimator
\texttt{lip\_ub\_F} reports $\sigma_{\max}(\nabla F)$ via power iteration
on $J_F^\top J_F$; this is logged as an over-restrictive diagnostic only,
since $\sigma_{\max}<1$ is sufficient (Banach contraction principle) but
not necessary for $\rho<1$ --- the gap can be huge for non-symmetric
$J_F$, as iter152 empirically confirms ($\sigma_{\max}\approx 17$ with
\texttt{iter\_conv\_rel}$\approx 0.02$ at K=128, demonstrating the
iteration converges fine even with large operator norm).  The
transition map $T_\theta$ is retained as a decomposition diagnostic
only; $\rho(\nabla T_\theta)<1$ is sufficient but not necessary for the
joint condition.

\paragraph{Architecture-agnostic constraint.}
The framework above is independent of any particular model architecture.
For any iteration mechanism --- alternative DEQ solvers, refinement
loops, recurrent layers, or future iterative components --- the same
condition $\rho(J_M)<1$ on the iteration map's Jacobian governs
asymptotic local convergence (Hartman--Grobman theorem applied to the
linearization at the fixed point).  Promotion of any such mechanism is
gated on \texttt{rho\_F < 1} (theoretical, when measurable on $F$ or its
analog $J_M$) or \texttt{iter\_conv\_rel < 0.05} at deepest K
(empirical operational signal).  Soft penalties on operator-norm
proxies were empirically refuted (iter155, 2026-05-13) as not
principled: they target the wrong condition AND cannot reliably
constrain spectral properties via soft pressure.  When formal
enforcement is needed, the principled mechanism is hard
parameterization (spectral normalization on $T_\theta$ component
layers, bounded-Lipschitz block parameterization, or learned
$c\cdot\Delta$ gain with hard projection), not coefficient-tuned soft
penalties.

\begin{proof}
Let $J=\nabla T(z^\star)$.  Since $\rho(J)<1$, the discrete Lyapunov theorem
implies that for any $Q\succ0$ there is a unique $P\succ0$ solving
\[
  J^\top P J-P=-Q.
\]
Equivalently, one may take the convergent series
\[
  P=\sum_{i=0}^{\infty}(J^\top)^i QJ^i .
\]
For the linearized error system $e_{k+1}=Je_k$, the quadratic function
$V(e)=e^\top Pe$ satisfies
\[
  V(Je)-V(e)=e^\top(J^\top PJ-P)e=-e^\top Qe.
\]
Thus the linearized system is exponentially stable.

For the nonlinear map, differentiability gives
\[
  T(z^\star+e)-z^\star = Je+r(e),
  \qquad
  \|r(e)\|=o(\|e\|).
\]
Choose a neighborhood where $\|r(e)\|\le\varepsilon\|e\|$.  Then
\[
\begin{aligned}
  V(Je+r)-V(e)
    &= -e^\top Qe + 2e^\top J^\top Pr + r^\top Pr \\
    &\le -\lambda_{\min}(Q)\|e\|^2
      +2\|J^\top P\|\varepsilon\|e\|^2
      +\|P\|\varepsilon^2\|e\|^2 .
\end{aligned}
\]
Taking $\varepsilon$ small enough makes the last two terms at most
$\frac12\lambda_{\min}(Q)\|e\|^2$.  Hence $V$ strictly decreases in a
neighborhood of $z^\star$, which implies local exponential stability.
\end{proof}

\begin{remark}[What the theorem does and does not say]
The condition is local and pointwise at the reached equilibrium.  It does not
give global uniqueness, global convergence, or a guarantee that arbitrary
initializations land in the same basin.  It justifies training pressure that
shrinks the local Jacobian around solver-reached states.  The code's K-sweep,
iterate-convergence, and reconstruction checks are the empirical validation
that the finite RevDEQ/Parcae solver behaves like a useful fixed-point model.
\end{remark}

\begin{remark}[Choosing the contraction object: $T_\theta$ vs $S$ vs $F$ — iter155 corrected]
\label{rem:contraction-objects}
The theorem applies to whatever map drives the iteration.  The actual Parcae
solver iterates the two-state cycle
\[
  F(y, z) = \big(D_A\, y + D_\beta\, T_\theta(z),\;
                D_A\, z + D_\beta\, T_\theta(D_A\, y + D_\beta\, T_\theta(z))\big),
\]
with $D_A = \mathrm{diag}(\bar A)$ and $D_\beta = \mathrm{diag}(1-\bar A)$
the per-dimension Parcae gates (so $\bar A$ and $\beta$ are model-dim
vectors, not scalars; matrix-multiplication order matters when they meet
the dense $J_T$).  This is \emph{not} the single-state convex blend
$S(z) = D_A z + D_\beta T_\theta(z)$ that one might naïvely write down.
The Jacobian of $F$ at the fixed point $(y^\star, z^\star) = (z^\star, z^\star)$
has block structure (with $J_T = \nabla T_\theta(z^\star)$):
\[
  \nabla F =
  \begin{bmatrix}
    D_A & D_\beta\, J_T \\
    D_\beta\, J_T\, D_A & D_A + D_\beta\, J_T\, D_\beta\, J_T
  \end{bmatrix}.
\]
The diagonal $D_A, D_\beta$ matrices do \emph{not} commute with $J_T$ in
general, so order is preserved as written; the K-sweep \texttt{lip\_ub\_F}
probe builds the JVP through the literal closure
$\texttt{a\_bar\_t}*y + (1-\texttt{a\_bar\_t})*\texttt{sb}(z, x_0; \bar B)$
(elementwise multiply), which gives \texttt{torch.autograd} the correct
order automatically.  $J_F$ couples $J_T$ through the off-diagonal
$D_\beta\, J_T$ blocks and through $D_\beta\, J_T\, D_\beta\, J_T$ in the
lower-right.  The gate-aligned \emph{empirical local-contraction
condition} is $\sigma_{\max}(J_F)<1$ (estimated by \texttt{lip\_ub\_F};
sufficient but not equivalent to $\rho(J_F)<1$, and the estimator itself
is a lower bound on $\sigma_{\max}$ rather than a hard upper bound — see
the honesty caveat in Section~\ref{sec:reg}).

The single-state surrogate $S$ and the transition map $T_\theta$ are kept
as advisory decomposition diagnostics, with the following
operator-norm relations clarifying what damping can and cannot do:

\begin{enumerate}[leftmargin=2em,itemsep=0.2em]
  \item \emph{For the convex-blend surrogate $S$}: by sub-additivity,
    $\sigma_{\max}(J_S) \le \bar A + (1-\bar A)\,\sigma_{\max}(J_T)$.  When
    $\sigma_{\max}(J_T) < 1$, this is sufficient for $\sigma_{\max}(J_S) < 1$
    (the bound is below $1$).  When $\sigma_{\max}(J_T) > 1$, however,
    $\bar A + (1-\bar A)\,\sigma_{\max}(J_T) > 1$ for every $\bar A < 1$:
    convex blending with the identity \emph{cannot} contract a positive
    expanding singular mode of $T$.  The same conclusion holds for
    eigenvalues of $J_S$: any positive real eigenvalue $\lambda_T > 1$ of
    $J_T$ produces $\bar A + (1-\bar A)\,\lambda_T > 1$.
  \item \emph{For the actual cycle $F$}: damping alone is even more limited.
    The cross-block $\beta\cdot J_T$ entries scale linearly with the
    transition magnitude, so a large $\sigma_{\max}(J_T)$ produces
    a large $\sigma_{\max}(J_F)$ via the off-diagonal blocks regardless
    of $\bar A$.  Bringing $\sigma_{\max}(J_F) < 1$ requires \emph{joint}
    pressure on $\bar A$ (toward the reversibility ceiling) \emph{and} on
    the transition parameters $\theta$ (to shrink $\sigma_{\max}(J_T)$).
\end{enumerate}

In particular: with $D_A, D_\beta$ per-dim and order preserved as written
in $\nabla F$ above, the same bound holds elementwise — damping alone
cannot rescue an expansive transition mode in either $S$ or $F$.

So $\rho(\nabla T_\theta) < 1$ \emph{is} sufficient for $\rho(\nabla S) < 1$
(scalar convex blend with $I$).  For the joint $J_F$ with per-dim,
non-commuting $D_A, D_\beta$ gates, the analogous implication is
\emph{not} a textbook spectral-radius bound — the upper-right block is
$D_\beta J_T$ rather than a convex combination, and the lower-left and
lower-right blocks introduce $D_\beta J_T D_A$ and $D_\beta J_T D_\beta J_T$
terms that depend on the eigenstructure of $J_T$ in a non-monotone way.
We do not state $\rho(\nabla T_\theta)<1 \Rightarrow \rho(\nabla F)<1$ as
a general guarantee; the safe stance is that the contraction guarantee
must be evaluated directly on $F$ (via $\sigma_{\max}(J_F)$ or a true
local-ball Lipschitz bound).  $T_\theta$ is retained as a decomposition
diagnostic only: a large $\sigma_{\max}(J_T)$ at iter145r/149/152
($\texttt{lip\_ub\_T}\in[22,65]$) attributes the F-side expansion to the
transition rather than to insufficient damping, but does not by itself
imply F is expansive (or contractive).
The gate-aligned remediation under \texttt{iteration\_F} therefore trains
$\bar A$ \emph{and} $\theta$ jointly through the F-side FD penalty.
iter156 escalates: (156a) is a \emph{heuristic} Ā-projection governor
that probes $\texttt{lip\_ub\_F}$ and adjusts $\bar A$ greedily but
without a monotonicity guarantee on $\sigma_{\max}(J_F)$; (156b)
introduces a learned $c\in(0,1]$ gain on $\Delta$ as a true bounded-
Lipschitz parameterization (the formal-guarantee tier) — combined with
F-side measurement, 156b can actually enforce a Lipschitz upper bound.
Sibling formal-tier paths: spectral normalization of $\Delta$,
bounded-Lipschitz block parameterization, or interval/explicit-Jacobian
estimation over a local ball.

A subtlety: the K-sweep \texttt{lip\_ub} probes use power iteration
($n\_\text{iters}=3$ by default), which converges to the dominant singular
value from below.  In short runs or when the dominant direction is not
quickly captured, the reported \texttt{lip\_ub} can underestimate
$\sigma_{\max}$.  A reading $\texttt{lip\_ub\_F}<1$ is therefore an
empirical local-contraction estimate, not a hard certificate; iter156's
hard governor design will provide projection-based enforcement, and a
true formal certificate requires either an interval/explicit-Jacobian
bound or a model-class change (spectral normalization, bounded-Lipschitz
layers, or a learned $c\in(0,1]$ gain on $\Delta$).
\end{remark}
