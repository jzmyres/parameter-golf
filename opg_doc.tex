\begin{abstract}
This document defines a \emph{proposed} RevDEQ backbone architecture as an explicit fixed-point map $T_x$ with a \emph{certifiable}
contraction budget, yielding a \textbf{unique} fixed point and \textbf{global} convergence via Banach.
The mainline design keeps \textbf{parallel attention + FFN} and \textbf{input-dependent dense routing}, but replaces ad-hoc state gates
with (i) an \textbf{exogenous} injection $b(x_0)$ and (ii) \textbf{Lipschitz-controlled} router scoring (SIPS and L2-distance options).
To make the convergence argument self-contained, we spell out simple sufficient conditions under which each submodule is \textbf{non-expansive}
(1-Lipschitz) under a chosen norm, and we provide an expressiveness discussion showing the architecture remains transformer-like on bounded domains.

\paragraph{Status.}
Theorems and proofs in the main body apply to the \emph{proposed} contractive design. Appendices document the \emph{current} code in
\texttt{train\_gpt.py} (RevDEQ + dense routers + MLA/gated SDPA + MoS/FSQ + optional self-refinement) and list the explicit gaps.
\end{abstract}

\section{Executive changes relative to the current code}
\label{sec:exec}

The current code (\texttt{train\_gpt.py}) implements a RevDEQ solver over a shared block with token-local injection gates, dense softmax routing,
MLA-style attention with post-SDPA head gates, and a dual MoS head (CTP+NTP) with FSQ. A late wallclock ramp optionally enables an outer
self-refinement loop that re-embeds predicted token distributions. This document proposes a \emph{certifiable} backbone map $T_x$ by:

\begin{enumerate}[leftmargin=2em,itemsep=0.25em]
  \item \textbf{Mainline scope}: the main body focuses on a \emph{single} iteration axis: the inner RevDEQ equilibrium solve for a strict contraction $T_x$.
  \item \textbf{Injection}: remove any state-dependent injection gate from the certified map. Use an \emph{exogenous} injection
        $b(x_0)$ that contains an identity path so the backbone cannot become input-independent by collapsing a learned gate.
  \item \textbf{Routing}: keep routing \emph{input-dependent} on the DEQ state $z$, but parameterize logits using a Lipschitz-controlled score
        (SIPS or L2-distance), yielding an explicit bound on router sensitivity.
  \item \textbf{Contraction shell}: wrap the routed update $G_\theta$ with a scalar $\tau\in(0,1)$ to ensure $T_x$ is a strict contraction:
        $T_x(z)=(1-\tau)\,b(x_0)+\tau\,G_\theta(z,x_0)$.
\end{enumerate}

\paragraph{Reader guide.}
Sections~\ref{sec:notation}--\ref{sec:convergence} define $T_x$ and give sufficient conditions for a unique fixed point.
Section~\ref{sec:expressive} discusses expressiveness under 1-Lipschitz constraints.

\paragraph{Guiding principle for iteration proposals.}
\emph{Every architectural change proposed in this document must preserve (or strengthen) the
contraction-mapping property required by the Banach fixed-point theorem.} A
proposal is admissible only if, after the change, $T_x$ remains a strict contraction
(Lipschitz constant $<1$) under the norm chosen in Section~\ref{sec:notation}.
Proposals should also be \textbf{simple} (one change at a time, ideally a single module replaced or one
constraint added) and \textbf{principled} (each change traceable to a specific sufficient condition in
Sections~\ref{sec:proj}--\ref{sec:modules}). Several candidate architectures listed in this
document (e.g.\ SIPS vs.\ L2-distance routing, RMSNorm vs.\ $\Pi_R$ projection,
MLA+SDPA vs.\ L2 attention) should be tested \emph{rigorously and thoroughly} against
each other under this rubric.

\section{Notation, norms, and Lipschitz constants}
\label{sec:notation}

Let $V$ be vocabulary size, $B$ batch size, $T$ sequence length, and $d$ model width.
Token IDs and next-token targets:
\[
  x \in \{0,\dots,V-1\}^{B\times T},\qquad
  y \in \{0,\dots,V-1\}^{B\times T}.
\]
Embeddings and states:
\[
  x_0 \in \mathbb{R}^{B\times T\times d},\qquad
  z \in \mathbb{R}^{B\times T\times d}.
\]

\paragraph{Norm choice.}
All Lipschitz statements in the main body use the Frobenius norm on tensors:
\[
  \|z\| := \|z\|_F = \sqrt{\sum_{b,t,i} z_{bti}^2}.
\]
This identifies $\mathbb{R}^{B\times T\times d}$ with a Euclidean space, which is complete.

\begin{definition}[Lipschitz constant]
For a map $F:\mathcal{X}\to\mathcal{X}$ on a normed space $(\mathcal{X},\|\cdot\|)$, define
\[
  \mathrm{Lip}(F) := \inf\{L\ge 0:\ \|F(u)-F(v)\|\le L\,\|u-v\|\ \forall u,v\in\mathcal{X}\}.
\]
We call $F$ \emph{non-expansive} if $\mathrm{Lip}(F)\le 1$ and a \emph{contraction} if $\mathrm{Lip}(F)<1$.
\end{definition}

\paragraph{Code normalization notation (appendices).}
The current code uses both parameter-free RMS normalization (\texttt{F.rms\_norm} via \texttt{\_rms\_norm}) and learnable RMSNorm modules.
In the appendices we write $\mathrm{rms\_norm}(\cdot)$ for the parameter-free version and $\mathrm{RMSNorm}(\cdot)$ for a learnable RMSNorm.
These are \emph{not} globally 1-Lipschitz without additional constraints; the certified design below uses explicit 1-Lipschitz projections.

\section{End-to-end forward algorithm (single DEQ solve; proposed)}
\label{sec:forward}

\paragraph{High-level algorithm.}
The proposed backbone runs a single RevDEQ equilibrium solve for a strict contraction map $T_x$:
\begin{lstlisting}
Inputs: token IDs x [B,T], targets y [B,T]
Hyperparams: K=num_layers, beta=deq_beta

# 1) Base input embedding (same as current code)
x0 = rms_norm( Emb(x) + BigramHashEmb(x) )        # BigramHashEmb optional

# 2) Certified RevDEQ equilibrium solve
z0 = x0                                           # warm start
z  = RevDEQ_Solve( T_x, z0, beta, K_eff )

# 3) Output head + losses (same as current code)
h = RMSNorm(z)
log p_CTP, log p_NTP = MoSHead(h)
loss = NLL(log p_NTP, y) + auxiliary losses
\end{lstlisting}

\paragraph{Scope note.}
The certified mainline scope is a single inner DEQ equilibrium solve of the strict contraction $T_x$; any outer self-refinement loop is orthogonal and is not part of the contraction proof.  The self-refinement loop (retained for experimental study) is documented separately in Appendix~\ref{app:refinement}.

\section{Inner loop: RevDEQ coupled-state solver}
\label{sec:deq}

RevDEQ maintains two states $y_k$ and $z_k$ and applies the fixed-point map twice per step:
\begin{align}
  y_{k+1} &= (1-\beta)\,y_k + \beta\, T_x(z_k),\\
  z_{k+1} &= (1-\beta)\,z_k + \beta\, T_x(y_{k+1}),
\end{align}
for $k=0,\dots,K-1$, with initialization $y_0=z_0$.

\begin{remark}[Convergence link]
If $T_x$ is a strict contraction with constant $k<1$, then the Picard iteration $z\leftarrow T_x(z)$ converges globally.
The RevDEQ relaxation parameter $\beta$ is a solver knob; a common sufficient stability range is $0<\beta<2/(k+1)$.
\end{remark}

\section{The proposed fixed-point map $T_x$}
\label{sec:map}

\subsection{1-Lipschitz projections (certified normalization)}
\label{sec:proj}

To keep the mainline certifiable, we use explicit non-expansive projections instead of unconstrained normalization.
For a radius $R>0$, define the Euclidean ball in $\mathbb{R}^{B\times T\times d}$:
\[
  \mathcal{B}_R := \{u:\ \|u\|\le R\}.
\]
Let $\Pi_R$ be the projection onto $\mathcal{B}_R$:
\[
  \Pi_R(u) := \arg\min_{v\in\mathcal{B}_R}\|u-v\|.
\]
This projection has a key property:
\begin{proposition}[Projection is 1-Lipschitz]
$\Pi_R$ is non-expansive: $\|\Pi_R(u)-\Pi_R(v)\|\le \|u-v\|$ for all $u,v$.
\end{proposition}

\subsection{Injection (no state-dependent gate)}
\label{sec:inj}

Define an exogenous additive injection
\begin{equation}
  \label{eq:bx0}
  b(x_0) := x_0 + U\,\Pi_R(x_0),
\end{equation}
where $U\in\mathbb{R}^{d\times d}$ is learned with a spectral norm constraint $\|U\|_2\le 1$ (Section~\ref{sec:modules}).

\begin{remark}[Why include the identity path $x_0$]
If injection were only $U\Pi_R(x_0)$, the model could drift toward input-independence by learning $U\approx 0$.
Including $x_0$ guarantees the fixed-point map remains input-dependent even if the learned adapter collapses.
\end{remark}

\subsection{Router input and scoring (SIPS and L2-distance)}
\label{sec:routing}

Let the router read a projected view of the current state plus injection:
\[
  r(z,x_0) := \Pi_R(z + b(x_0)) \in \mathbb{R}^{B\times T\times d}.
\]
Let $q(z,x_0)=W_q\,r(z,x_0)$ with $\|W_q\|_2\le 1$. The router defines logits $s\in\mathbb{R}^{B\times T\times E}$
for a combined expert pool $E=E_{\text{attn}}+E_{\text{ffn}}$ and dense weights
\[
  w(z,x_0)=\mathrm{softmax}(s(z,x_0))\in\Delta^{E-1}.
\]

\paragraph{Option A (SIPS).}
For expert anchors $k_j\in\mathbb{R}^{d_r}$ and bounded transforms $\phi,\psi:[0,\infty)\to[0,1]$,
\[
  s_j = \gamma\;\phi(\|q\|)\;\psi(\|k_j\|)\;\cos(q,k_j),
\]
with a bounded scale $\gamma\in[0,\gamma_{\max}]$.

\paragraph{Option B (L2-distance).}
For prototypes $c_j\in\mathbb{R}^{d_r}$,
\[
  s_j = \rho\!\left(-\gamma\,\|q-c_j\|_2^2\right),
\]
where $\rho$ is a 1-Lipschitz saturation (e.g.\ $\rho(t)=\tanh(t)$) and $\gamma\in[0,\gamma_{\max}]$.
Note that $\|q-c\|^2=\|q\|^2+\|c\|^2-2q^\top c$, so this can be implemented efficiently using dot products and norms.

\subsection{Parallel routed expert update $G_\theta$}
\label{sec:Gtheta}

Define the shared expert input
\[
  u(z,x_0) := \Pi_R(z+b(x_0)).
\]
All experts read $u$. Let $\{A_e\}_{e=1}^{E_{\text{attn}}}$ be attention experts and $\{M_e\}_{e=1}^{E_{\text{ffn}}}$ be FFN experts,
each constructed to be 1-Lipschitz (Section~\ref{sec:modules}).
Split mixture weights:
\[
  w^A_e := w_e,\ e=1..E_{\text{attn}},\qquad
  w^M_e := w_{E_{\text{attn}}+e},\ e=1..E_{\text{ffn}}.
\]
Compute dense mixtures:
\begin{align}
  \Delta_{\text{attn}}(z,x_0) &= \sum_{e=1}^{E_{\text{attn}}} w^A_e(z,x_0)\,A_e(u(z,x_0)),\\
  \Delta_{\text{ffn}}(z,x_0)  &= \sum_{e=1}^{E_{\text{ffn}}}  w^M_e(z,x_0)\,M_e(u(z,x_0)).
\end{align}
Combine in parallel and apply a \textbf{single} output projection on the combined update
(the $\tfrac12$ matches the stabilizing scale used in the current code):
\begin{equation}
  \label{eq:Gtheta}
  G_\theta(z,x_0) := \Pi_R\!\left(\tfrac12\Big(\Delta_{\text{attn}}(z,x_0)+\Delta_{\text{ffn}}(z,x_0)\Big)\right).
\end{equation}

\begin{remark}[Minimal principled norms: $\Pi_R$ inside $T_x$, normalization outside]
\label{rem:norm_separation}
\textbf{Inside} the DEQ fixed-point map $T_x(z)$ (i.e., inside the block forward),
use \emph{only} non-expansive clamps $\Pi_R$, not learnable RMSNorm or LayerNorm.
\textbf{Outside} the fixed-point map (embeddings, final output head), learnable
normalizations may be kept for optimization without affecting the DEQ contraction guarantee.

Concretely, $T_x$ uses exactly \textbf{two} $\Pi_R$ projections:
\begin{enumerate}[leftmargin=2em]
  \item \textbf{Pre-projection} (shared input): $u = \Pi_R(z + b(x_0))$ feeds the same bounded
        vector to routers \emph{and} all experts.
  \item \textbf{Post-projection} (combined update): $G_\theta = \Pi_R(\tfrac12(\Delta_{\text{attn}} + \Delta_{\text{ffn}}))$.
\end{enumerate}
No other norms or clamps appear inside $T_x$.  Learnable norms (RMSNorm) are
reserved for outside the solve: embedding normalization, the final output-head
norm, and refinement soft-embedding normalization.

\emph{Why not RMSNorm inside $T_x$?}  RMSNorm is \textbf{not} globally 1-Lipschitz
(its Jacobian norm diverges as $\|x\|\to 0$).  Using it inside the fixed-point
map complicates the contraction analysis.  $\Pi_R$ is 1-Lipschitz by
construction for any $R>0$, giving the contraction guarantee ``for free.''

\emph{Why not remove all clamps?}  Without $\Pi_R$, the bounded-domain assumptions
that make routers, softmax, and attention well-behaved in bf16 are lost, and
$\tau<1$ alone cannot reliably prevent saturation or magnitude blow-up unless
strict operator-norm constraints are enforced \emph{everywhere} (more complex
than two $\Pi_R$ projections).
\end{remark}

\subsection{Contractive wrapper (the map actually solved)}
\label{sec:Tx}

Finally define
\begin{equation}
  \label{eq:Tx}
  T_x(z) := (1-\tau)\,b(x_0) + \tau\,G_\theta(z,x_0),
  \qquad 0<\tau\le\tau_{\max}<1.
\end{equation}
$\tau$ may be fixed, or predicted by a bounded head and then clamped by $\tau_{\max}$.

\section{Module-by-module simplicity and 1-Lipschitz proof sketches}
\label{sec:modules}

This section gives sufficient conditions to make each component of $T_x$ non-expansive under $\|\cdot\|_F$.
The guiding rule is: \emph{use only (i) linear maps with operator norm $\le 1$, (ii) 1-Lipschitz nonlinearities,
and (iii) 1-Lipschitz projections/clamps to keep states bounded.}

\subsection{Linear maps}
\begin{proposition}[Linear Lipschitz constant]
For $f(u)=Wu$, $\mathrm{Lip}(f)=\|W\|_2$ (spectral norm). In particular, if $\|W\|_2\le 1$ then $f$ is 1-Lipschitz.
\end{proposition}
\begin{remark}[How to enforce $\|W\|_2\le 1$]
Use spectral normalization or parameterize $W$ via a constrained factorization (e.g.\ $W=\alpha\tilde W$ with $\alpha\le 1/\|\tilde W\|_2$).
\end{remark}

\subsection{Elementwise nonlinearities}
\begin{proposition}[Standard 1-Lipschitz activations]
The following are 1-Lipschitz on $\mathbb{R}$: $\tanh$, $\mathrm{ReLU}$, and $\mathrm{LeakyReLU}(\cdot;\eta)$ for $\eta\in[0,1]$.
Elementwise application preserves 1-Lipschitzness under $\|\cdot\|_F$.
\end{proposition}

\subsection{Rotary embeddings / orthogonal transforms}
\begin{proposition}[Orthogonal transforms are 1-Lipschitz]
If $Q$ is orthogonal ($Q^\top Q=I$), then $\|Qu-Qv\|=\|u-v\|$. Therefore $Q$ is 1-Lipschitz.
\end{proposition}
\begin{remark}
RoPE applies a block-diagonal rotation to pairs of coordinates, which is orthogonal.
\end{remark}

\subsection{Softmax}
\label{sec:softmax_lip}
\begin{proposition}[Softmax Jacobian bound in $\ell_2$ (sketch)]
Let $\sigma:\mathbb{R}^E\to\Delta^{E-1}$ be softmax. Its Jacobian is $J=\mathrm{diag}(p)-pp^\top$ where $p=\sigma(s)$.
One can show $\|J\|_2\le 1/2$ for all $s$, hence softmax is $1/2$-Lipschitz in $\ell_2$:
$\|\sigma(a)-\sigma(b)\|_2\le \tfrac12\|a-b\|_2$.
\end{proposition}

\subsection{Router scoring: explicit Lipschitz bounds (sketch)}
\label{sec:router_lip}

\begin{proposition}[L2-distance logits are Lipschitz on bounded sets (sketch)]
Fix $\gamma\in[0,\gamma_{\max}]$ and let prototypes satisfy $\|c_j\|_2\le R_c$. Suppose the router query satisfies $\|q\|_2\le R_q$.
Define logits $s_j(q)=\rho(-\gamma\|q-c_j\|_2^2)$ where $\rho$ is 1-Lipschitz.
Then each $s_j$ is Lipschitz with
\[
  \mathrm{Lip}(s_j)\ \le\ 2\gamma_{\max}(R_q+R_c).
\]
\end{proposition}
\begin{remark}[Reason]
The gradient of $-\gamma\|q-c\|^2$ w.r.t.\ $q$ is $-2\gamma(q-c)$, whose norm is bounded by $2\gamma(\|q\|+\|c\|)$.
Composition with 1-Lipschitz $\rho$ does not increase the bound.
\end{remark}

\begin{corollary}[Dense weights inherit a bound via softmax]
If $s:\mathbb{R}^{d_r}\to\mathbb{R}^E$ is $L_s$-Lipschitz in $\ell_2$, then $w=\mathrm{softmax}\circ s$ is $(L_s/2)$-Lipschitz in $\ell_2$.
\end{corollary}

\begin{remark}[SIPS option]
SIPS can be treated similarly by ensuring (i) bounded scale $\gamma$, (ii) bounded anchor norms, and (iii) a normalization of $q$ that is well-behaved
on the solver region (e.g.\ by projecting $q$ away from 0 before forming $\cos(\cdot,\cdot)$). We treat SIPS as an alternative implementation option
and rely on the same ``bounded query + bounded scale'' principle to control $L_s$.
\end{remark}

\subsection{Dense routed mixtures}
\begin{proposition}[Mixture Lipschitz bound (sufficient condition)]
Assume (i) each expert $E_j$ is 1-Lipschitz, (ii) expert outputs are bounded on the solver region:
$\|E_j(u)\|\le B$ for all $u$ encountered, and (iii) router weights $w(\cdot)$ are $L_w$-Lipschitz in $\ell_1$.
Then the mixture $F(u)=\sum_j w_j(u)E_j(u)$ is Lipschitz with
\[
  \mathrm{Lip}(F)\ \le\ 1 + B\,L_w.
\]
\end{proposition}
\begin{remark}[Practical non-expansive mixture]
To make $G_\theta$ provably non-expansive, either (a) ensure $L_w$ is very small (Lipschitz-controlled logits + softmax),
or (b) add an output projection: $\Delta\leftarrow \Pi_R(\Delta)$, which caps $B$ and is 1-Lipschitz.
\end{remark}

\subsection{Certified attention and FFN experts}
\paragraph{Attention expert $A_e$ (L2 attention; MLA-compatible).}
Define a single expert as a composition of 1-Lipschitz parts:
\[
  q = W^Q_e\,u,\quad k = W^K_e\,u,\quad v = W^V_e\,u,\qquad \|W^\cdot_e\|_2\le 1,
\]
optionally followed by RoPE rotations (1-Lipschitz). For each token position $t$, define L2 attention weights over previous positions $j\le t$:
\[
  a_{tj} = \frac{\exp(-\gamma\|q_t-k_j\|_2^2)}{\sum_{i\le t}\exp(-\gamma\|q_t-k_i\|_2^2)},\qquad
  o_t = \sum_{j\le t} a_{tj}\,v_j.
\]
Finally project the output: $A_e(u)=\Pi_R(W^O_e\,o)$ with $\|W^O_e\|_2\le 1$.
Under bounded states (enforced by $\Pi_R$ on $u$) and bounded $\gamma$, the scoring map is Lipschitz (Section~\ref{sec:router_lip})
and L2 self-attention admits explicit Lipschitz bounds (see \cite{l2_attention} for a detailed treatment).

\paragraph{FFN expert $M_e$ (1-Lipschitz MLP).}
A simple 1-Lipschitz FFN expert is
\[
  M_e(u) = \Pi_R\!\left(W^{(2)}_e\,\phi(W^{(1)}_e\,u)\right),
\]
where $\|W^{(1)}_e\|_2\le 1$, $\|W^{(2)}_e\|_2\le 1$, and $\phi$ is 1-Lipschitz (e.g.\ $\tanh$, ReLU, or GroupSort).
GroupSort networks in particular provide strong approximation results within the Lipschitz class \cite{groupsort}.

\section{Convergence guarantee: Banach + contraction shell}
\label{sec:convergence}

\begin{theorem}[Banach contraction mapping principle]
Let $(\mathcal{X},\|\cdot\|)$ be complete and $T:\mathcal{X}\to\mathcal{X}$ satisfy $\|T(u)-T(v)\|\le k\|u-v\|$ for some $k\in[0,1)$.
Then $T$ has a unique fixed point $u^\star$, and $u_{n+1}=T(u_n)$ converges to $u^\star$ for any $u_0\in\mathcal{X}$.
\end{theorem}

\begin{corollary}[Certified design rule]
If $G_\theta(\cdot,x_0)$ is non-expansive in $z$ (i.e.\ $\mathrm{Lip}_z(G_\theta)\le 1$), then $T_x$ in \eqref{eq:Tx} is a strict contraction
with constant at most $\tau_{\max}<1$. Therefore $T_x$ has a unique fixed point and the equilibrium solve is globally well-posed.
\end{corollary}

\begin{remark}[Fixed-point uniqueness vs expert ``uniqueness'']
Banach guarantees a \emph{unique fixed point} $z^\star$ for a given input $x_0$; it does not guarantee that different experts in the MoE bank
are distinct functions. Expert diversity is a separate modeling goal typically enforced by routing health constraints and/or orthogonality diagnostics
(as used in the current code).
\end{remark}

\section{Expressiveness (why this remains transformer-like)}
\label{sec:expressive}

\paragraph{1-Lipschitz does not mean weak.}
Modern LLMs operate on bounded hidden states due to normalization and finite precision. On bounded domains, 1-Lipschitz function classes can still be rich.

\paragraph{Universal approximation within a Lipschitz class (sketch).}
GroupSort networks with norm-constrained linear maps can approximate any 1-Lipschitz function on compact sets (Anil et al.).
Thus, the FFN experts can be expressive while remaining certifiably non-expansive.

\paragraph{Transformer-like behavior from the equilibrium map.}
If routing is chosen to be nearly input-only (small $L_w$) and $G_\theta$ is expressive in $x_0$, then the fixed point can behave like a deep transformer.
RevDEQ iteration provides implicit depth (iterated application of a shared block), while dense MoE provides additional capacity without sparsity.

\section{Head and losses (code-aligned; not part of the contraction proof)}
\label{sec:loss}

After the DEQ solve, both the proposed and current models use a dual MoS head (CTP+NTP) with FSQ in the rank space:
\[
  h=\mathrm{RMSNorm}(z),\qquad
  \log p_{\text{CTP}},\ \log p_{\text{NTP}} = \mathrm{MoSHead}(h).
\]
The current training objective in \texttt{train\_gpt.py} is:
\[
  L = L_{\text{NTP}} + \lambda_{\text{CTP}}L_{\text{CTP}}
    + \lambda_{\text{bal}}L_{\text{bal}}
    + \lambda_{\text{health}}L_{\text{health}}
    + \lambda_{\text{mos}}L_{\text{mos-ortho}}
    + \lambda_{\text{blk}}L_{\text{block-ortho-aux}},
\]
where $L_{\text{NTP}}=\mathrm{NLL}(\log p_{\text{NTP}},y)$ and $L_{\text{CTP}}=\mathrm{NLL}(\log p_{\text{CTP}},x)$.
The CTP weight is refinement-gated in code:
\[
  \lambda_{\text{CTP}} = 0.05\,R\cdot \mathrm{clip}\!\left(\frac{\alpha}{0.5},\,0,\,1\right),
\]
with $R=\texttt{num\_refinements}$ (often 0 early) and $\alpha=\texttt{\_refine\_mix\_alpha}\in[0,0.5]$.

\paragraph{Routing auxiliary losses (summary).}
The code tracks two kinds of routing penalties:
\begin{itemize}[leftmargin=2em,itemsep=0.25em]
  \item $L_{\text{bal}}$: MSE-to-uniform on mean expert shares for the attention and MLP routers (plus a strongly upweighted MoSHead balance term to prevent dead head experts).
  \item $L_{\text{health}}$: barrier-style penalties that target the final-only constraints, including per-expert min-share threshold $0.6/E$ and balance CV threshold $0.20$,
        multiplied by a late-phase \texttt{health\_scale} ramp.
\end{itemize}

\section{Self-refinement loop (orthogonal; optional arch, testable iteration)}
\label{app:refinement}

This appendix describes an \emph{orthogonal} outer refinement loop that can be
enabled independently of the certified $T_x$ solver. It is \textbf{not} part
of the contraction proof and does not affect Banach uniqueness of the inner
DEQ fixed point — each outer refinement $r$ solves a fresh contraction
$T_{x^{(r)}}$ to its unique fixed point, with a new exogenous input
$x^{(r)}$ derived from the previous solve's prediction.

\subsection{Initial input embedding ($r=0$)}
\[
  x_0^{(0)} \;=\; \mathrm{rms\_norm}\!\left(E[x] + \mathrm{BigramHashEmb}(x)\right).
\]

\subsection{Refinement distribution ($r>0$)}
At the end of solve $r-1$, define $h^{(r-1)}=\mathrm{RMSNorm}(z^{(r-1)})$ and compute:
\[
  \log p_{\text{CTP}}^{(r-1)},\ \log p_{\text{NTP}}^{(r-1)} \;=\; \mathrm{MoSHead}(h^{(r-1)}).
\]
Convert log-probabilities to probabilities in fp32 and define a shifted NTP distribution:
\[
  p_{\text{NTP,shift}}^{(r-1)}[t] \equiv
  \begin{cases}
    p_{\text{NTP}}^{(r-1)}[0] & t=0,\\
    p_{\text{NTP}}^{(r-1)}[t-1] & t\ge 1.
  \end{cases}
\]
Then
\[
  p_{\text{mix}}^{(r-1)}[t] =
  \begin{cases}
    p_{\text{CTP}}^{(r-1)}[0] & t=0,\\
    \tfrac12 p_{\text{CTP}}^{(r-1)}[t] + \tfrac12 p_{\text{NTP,shift}}^{(r-1)}[t] & t\ge 1.
  \end{cases}
\]

\subsection{Soft embedding and coupling}
Approximate the expected embedding under $p_{\text{mix}}$ with a top-$\kappa$ truncation (current default $\kappa=64$),
then mix with the previous refined input:
\[
  x_0^{(r)} \;=\; \alpha\,x_{\text{soft}}^{(r)} + (1-\alpha)\,x_0^{(r-1)},
\]
where $\alpha=\texttt{\_refine\_mix\_alpha}\in[0,0.5]$ is ramped up when refinement is enabled and the previous refined input is detached.

\subsection{Why this preserves the certified design}
For each fixed refinement index $r$, $x^{(r)}_0$ is a \emph{constant} input to the
inner DEQ solve.  The Banach guarantee (Corollary in Section~\ref{sec:convergence})
applies per-refinement: each outer step converges to the unique fixed point
$z^{\star(r)}$ of $T_{x^{(r)}_0}$.  Refinement changes the \emph{input argument}
of the contraction but not the Lipschitz constants of the map.  The detach on
$x^{(r-1)}_0$ and the bounded blending coefficient $\alpha\le 0.5$ keep the
outer loop from introducing unbounded gradients.
