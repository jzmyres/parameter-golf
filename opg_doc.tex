\begin{abstract}
The previous project document enforced \emph{global} convergence of the RevDEQ fixed-point solve by making the backbone map a
\textbf{strict global contraction} (Banach). In practice, the required ingredients
(ball projections $\Pi_R$, spectral-norm constraints on all linears, and an exogenous contraction shell)
significantly reduce expressiveness and degrade performance.

This revision replaces the global-contraction requirement with a \textbf{Lyapunov (local) stability} guarantee:
for each input $x_0$, we train the backbone map $T_\theta(\cdot,x_0)$ so that the equilibrium $z^\star$
found by the RevDEQ solver is a \textbf{strict local attractor}. Concretely, we enforce a \emph{local} condition
on the Jacobian at the equilibrium, $\rho(J_{z^\star})<1$, where $J_{z^\star}=\nabla_z T_\theta(z^\star,x_0)$ and $\rho(\cdot)$ is the spectral radius.
This condition implies (via a quadratic Lyapunov function) that the fixed point is locally exponentially stable,
so fixed-point iteration (and damped variants such as RevDEQ) converges from initial states in its basin of attraction.

Architecturally, we restore a \textbf{fully expressive} transformer-like block inside $T_\theta$:
\textbf{no ball projections}, \textbf{no spectral normalization constraints}, and \textbf{standard FlashAttention (MLA + SDPA)}
instead of L2-attention tricks. Stability is encouraged by (i) a \textbf{learnable RMSNorm preconditioner} before \emph{every} linear projection,
(ii) standard bounded-derivative nonlinearities (e.g.\ SiLU/GELU/SwiGLU), and (iii) a \textbf{single, boundary-only Lyapunov penalty}
computed with one efficient vector--Jacobian product (VJP) at the detached equilibrium state, using a \textbf{persistent power-iteration vector}
carried across training steps to reliably target the dominant Jacobian direction.

The result is a training recipe that isolates the expensive unrolled trajectory (handled by RevDEQ's reversible solver)
from stability regularization (handled by one boundary VJP), recovering expressiveness while retaining a rigorous
fixed-point convergence guarantee \emph{within the learned basin}. 
\end{abstract}

\section{Executive changes relative to the previous (Banach-contractive) document}
\label{sec:exec}

The previous document proved global uniqueness and global convergence by constructing a strict contraction map using:
(i) Euclidean ball projections $\Pi_R$ inside the map, (ii) spectral-norm constraints $\|W\|_2\le 1$ for all linears, and
(iii) an exogenous contraction shell parameter $\tau<1$ so that $\mathrm{Lip}(T_x)<1$ everywhere.

This revision explicitly \textbf{drops global contraction} and instead adopts \textbf{Lyapunov local stability at the reached equilibrium}.
The concrete changes are:

\begin{enumerate}[leftmargin=2em,itemsep=0.25em]
  \item \textbf{Convergence theory}: replace Banach/global contraction with \textbf{Lyapunov (local) stability} for the discrete-time dynamical system
        $z_{k+1}=T_\theta(z_k,x_0)$, guaranteed when $\rho(\nabla_z T_\theta(z^\star,x_0))<1$ at the equilibrium $z^\star$ (Section~\ref{sec:lyapunov}).
  \item \textbf{Remove hard contraction constraints}: remove all $\Pi_R$ projections, remove all spectral normalization constraints, and remove the analytic $\tau$-shell.
        These were the main sources of lost expressiveness.
  \item \textbf{Restore standard attention}: use \textbf{FlashAttention-friendly scaled dot-product attention} (MLA + SDPA) rather than L2-distance attention and
        the homogeneous-coordinate trick.
  \item \textbf{Stabilize via soft regularization + preconditioning}: add a \textbf{learnable RMSNorm} before \emph{every} linear projection
        (router, Q/K/V/O, and MLP linears) and use standard nonlinearities (SiLU/GELU/SwiGLU).
  \item \textbf{Efficient Lyapunov penalty}: enforce $\rho(J_{z^\star})\lesssim\gamma$ with a single boundary VJP at $z^\star$ (Section~\ref{sec:algorithm}),
        using a \textbf{persistent} one-step power-iteration vector to reliably target the dominant Jacobian direction.
        This avoids caching or differentiating through the full forward trajectory.
\end{enumerate}

\paragraph{Reader guide.}
Section~\ref{sec:arch} defines the new expressive backbone map.
Section~\ref{sec:algorithm} gives the \emph{robust + efficient} training algorithm (RevDEQ + boundary Lyapunov penalty).
Section~\ref{sec:lyapunov} states the Lyapunov stability conditions and provides a rigorous convergence proof.

\paragraph{Guiding principle for iteration proposals (updated).}
\emph{Every architectural change proposed in this document must preserve solver robustness while keeping the model maximally expressive.}
We no longer require global contraction. Instead, proposals should:
(i) maintain or improve empirical convergence of the RevDEQ inner solve, and
(ii) keep the learned equilibria locally stable by driving $\rho(\nabla_z T_\theta(z^\star,x_0))$ below a target $\gamma<1$ on the training distribution.

\section{Notation and dynamical-system view}
\label{sec:notation}

Let $V$ be vocabulary size, $B$ batch size, $T$ sequence length, and $d$ model width.
Token IDs and next-token targets:
\[
  x \in \{0,\dots,V-1\}^{B\times T},\qquad
  y \in \{0,\dots,V-1\}^{B\times T}.
\]
Embeddings and DEQ states:
\[
  x_0 \in \mathbb{R}^{B\times T\times d},\qquad
  z \in \mathbb{R}^{B\times T\times d}.
\]

\paragraph{Norm.}
Unless otherwise stated, we use the Frobenius norm on tensors:
\[
  \|z\| := \|z\|_F = \sqrt{\sum_{b,t,i} z_{bti}^2}.
\]
This identifies $\mathbb{R}^{B\times T\times d}$ with a Euclidean space (complete).

\begin{definition}[Fixed point and equilibrium map]
For a fixed input embedding $x_0$, define the backbone map $T_\theta(\cdot,x_0):\mathbb{R}^{B\times T\times d}\to\mathbb{R}^{B\times T\times d}$.
A tensor $z^\star$ is a \emph{fixed point} (equilibrium) if
\[
  z^\star = T_\theta(z^\star, x_0).
\]
\end{definition}

\begin{definition}[Spectral radius]
For a square linear operator (matrix) $A$, its spectral radius is
\[
  \rho(A) := \max\{|\lambda| : \lambda \text{ is an eigenvalue of } A\}.
\]
\end{definition}

\paragraph{Key shift (global $\Rightarrow$ local).}
Banach required $\mathrm{Lip}(T_\theta(\cdot,x_0))<1$ \emph{for all $z$}.
Here we only require a \textbf{local} condition at the equilibrium we actually reach:
\[
  \rho\!\left(\nabla_z T_\theta(z^\star,x_0)\right) < 1,
\]
which implies $z^\star$ is a \emph{strict local attractor} (Section~\ref{sec:lyapunov}).
This does \emph{not} guarantee global uniqueness: multiple equilibria may exist, and initialization selects the basin.

\subsection{Input embedding}
We retain the existing embedding stack:
\begin{equation}
  \label{eq:x0}
  x_0 = \mathrm{rms\_norm}\!\left(E[x] + \mathrm{BigramHashEmb}(x)\right),
\end{equation}
where \texttt{BigramHashEmb} is optional and $\mathrm{rms\_norm}$ denotes the parameter-free RMS normalization currently used in code.
(Any embedding-side normalization is outside the DEQ stability argument.)

\subsection{NormedLinear: learnable RMSNorm before every linear}
\label{sec:normedlinear}

A central design choice is to insert a learnable RMSNorm \emph{before every} linear map used inside $T_\theta$.
Define a reusable primitive:
\begin{equation}
  \label{eq:normedlinear}
  \mathrm{NormedLinear}(h;W,b,g) \;:=\; W\,\mathrm{RMSNorm}(h;g) + b,
\end{equation}
where $\mathrm{RMSNorm}(\cdot;g)$ is learnable (scale $g$, with $\varepsilon$ for numerical stability).
We use \eqref{eq:normedlinear} for:
router projections, Q/K/V/O projections, and both MLP linears.

\begin{remark}[Why this helps stability without killing expressiveness]
RMSNorm preconditioning controls activation scale and reduces sensitivity to weight growth,
making it easier for training to satisfy $\rho(J_{z^\star})<1$ without forcing $\|W\|_2\le 1$ globally.
Unlike hard spectral constraints or $\Pi_R$ projections, this does not cap representational capacity away from the equilibrium.
\end{remark}

\subsection{Backbone block: dense routing over attention + MLP experts}
\label{sec:block}

Let $u = z + x_0$ be the combined state+input view.
Compute a shared normalized representation $h = \mathrm{RMSNorm}(u)$.

\paragraph{Router with un-normalized sigmoid gate.}
We maintain dense routing over a combined expert pool $E = E_{\text{attn}} + E_{\text{mlp}}$
with a \textbf{per-expert sigmoid gate that is NOT renormalized}:
\begin{align}
  w_{\text{alloc}} &= \mathrm{softmax}(\text{score}(h, K_r)) \in \Delta^{E-1}, \label{eq:router_alloc}\\
  g &= \sigma(W_g\,h + b_g) \in [0,1]^E, \label{eq:router_gate}\\
  w &= w_{\text{alloc}} \odot g, \qquad \sum_j w_j \le 1. \label{eq:router_final}
\end{align}
The softmax in \eqref{eq:router_alloc} allocates relative budget across experts (sums to 1).
The sigmoid gate in \eqref{eq:router_gate} independently scales each expert's contribution.
Crucially, the product in \eqref{eq:router_final} is \textbf{not renormalized}: the total expert
weight $\sum_j w_j$ can be strictly less than 1.

\begin{remark}[Why un-normalized is more expressive]
When the gate suppresses all experts ($g\to 0$), the mixture $\Delta_\theta(z,x_0)\to 0$ and
$T_\theta(z,x_0)\to x_0$.  This gives the model a ``do nothing'' mode for tokens already
near equilibrium, which is semantically meaningful for DEQ: the solver can recognize convergence
token-by-token.  Forcing $\sum w_j=1$ (as the previous logit-space formulation did) removes
this degree of freedom.
\end{remark}

(Any scoring parameterization---L2 distance with $\tanh$, dot-product, SIPS---can be used
for computing the route logits in \eqref{eq:router_alloc}.)

\paragraph{Attention experts (fully independent per-expert MLA).}
Each attention expert $e$ has its \textbf{own complete MLA pipeline with zero shared parameters}:
\begin{enumerate}[leftmargin=2em,itemsep=0.1em]
  \item \textbf{Per-expert Q} (low-rank): $Q_e = W^{Q,\text{up}}_e \cdot W^{Q,\text{down}}_e \cdot h$,
    output dimension $H \times d_{\text{head}} + H$ (gate logits appended).
  \item \textbf{Per-expert KV compression} (low-rank): $\ell_e = W^{KV,\text{up}}_e \cdot W^{KV,\text{down}}_e \cdot h$,
    followed by per-expert RMSNorm (learned scale $g_e$, not shared across experts).
  \item \textbf{Per-expert KV decompression}: $K^{\text{nope}}_e = W^{K}_e \cdot \ell_e$, $V_e = W^{V}_e \cdot \ell_e$
    (independent dictionaries, not shared).
  \item \textbf{Per-expert $K^{\text{rope}}$} (low-rank): $K^{\text{rope}}_e = W^{\text{kr,up}}_e \cdot W^{\text{kr,down}}_e \cdot h$.
  \item \textbf{Per-expert output projection $W^O_e$} (low-rank): mixes heads independently per expert.
\end{enumerate}
All $E$ experts are packed into the head dimension ($E \times H$ query heads, $E \times H_{\text{kv}}$ KV heads)
for a \textbf{single FlashAttention/SDPA call}. GQA ratio $H/H_{\text{kv}}$ is preserved. After SDPA, per-expert-per-head sigmoid gates are applied, then the low-rank output projection $W^O_e$:
\[
  A_e(h) = W^{O,\text{up}}_e \cdot W^{O,\text{down}}_e \cdot \big(\sigma(g_e)\odot \mathrm{SDPA}(Q_e,K_e,V_e)\big).
\]

\paragraph{MLP experts (dense MoE, SwiGLU/GELU).}
For MLP expert $e$, we use a gated MLP such as SwiGLU:
\[
  a_e = \mathrm{NormedLinear}(h;W^{(a)}_e,b^{(a)}_e,g^{(a)}_e),\qquad
  b_e = \mathrm{NormedLinear}(h;W^{(b)}_e,b^{(b)}_e,g^{(b)}_e),
\]
\[
  m_e = \phi(a_e)\odot b_e,\qquad
  M_e(h) = \mathrm{NormedLinear}(m_e;W^{(2)}_e,b^{(2)}_e,g^{(2)}_e),
\]
with $\phi=\mathrm{SiLU}$ or $\mathrm{GELU}$.

\paragraph{Dense mixture and residual update.}
Let the expert outputs be collected as $\{E_j(h)\}_{j=1}^E$ with $E_j\in\{A_e,M_e\}$.
Compute the dense mixture:
\begin{equation}
  \label{eq:mixture}
  \Delta_\theta(z,x_0) := \sum_{j=1}^{E} w_j(z,x_0)\,E_j(h),
  \qquad h = \mathrm{RMSNorm}(z+x_0).
\end{equation}

\paragraph{Fixed-point map (expressive, unclamped).}
We define the equilibrium map as:
\begin{equation}
  \label{eq:Tx_new}
  T_\theta(z,x_0) := x_0 + \Delta_\theta(z,x_0).
\end{equation}
This map is fully expressive (no $\Pi_R$, no $\|W\|_2$ constraints) and uses standard SDPA attention.
Stability is enforced \emph{only} at the reached equilibrium using the Lyapunov penalty.

\begin{remark}[Why keep an explicit $x_0$ injection]
Even without a contraction proof, an explicit injection makes input-dependence structural:
if the expert bank collapses to zero, $T_\theta(z,x_0)=x_0$ so the equilibrium remains input-dependent.
This avoids the degenerate ``input-independent attractor'' failure mode.
\end{remark}

\section{RevDEQ solver and the efficient Lyapunov-regularized training algorithm}
\label{sec:algorithm}

This section presents the robust training algorithm requested:
an efficient \textbf{RevDEQ + Lyapunov} procedure that
(i) uses RevDEQ for the deep unrolled trajectory, and
(ii) computes a stability penalty using only a \textbf{single} VJP at the detached equilibrium boundary.

\subsection{Phase 1: RevDEQ forward pass (locating an equilibrium)}
\label{sec:phase1}

RevDEQ maintains two coupled states $y_k$ and $z_k$ and applies $T_\theta$ twice per step:
\begin{align}
  y_{k+1} &= (1-\beta)\,y_k + \beta\, T_\theta(z_k,x_0),\\
  z_{k+1} &= (1-\beta)\,z_k + \beta\, T_\theta(y_{k+1},x_0),
\end{align}
initialized with $y_0=z_0=x_0$ (warm start), and run for $K$ steps or until convergence.

\begin{lstlisting}
Inputs: token IDs x [B,T], targets y [B,T]
Hyperparams: K_max, beta in (0,1], eps_tol

# 1) Embed input
x0 = rms_norm( Emb(x) + BigramHashEmb(x) )  # optional BigramHashEmb

# 2) RevDEQ solve (forward)
y_state = x0
z_state = x0
for k in 0..K_max-1:
    y_next = (1-beta)*y_state + beta*T_theta(z_state, x0)
    z_next = (1-beta)*z_state + beta*T_theta(y_next,  x0)
    if ||z_next - z_state||_2 < eps_tol:
        break
    y_state, z_state = y_next, z_next

z_star = z_next                       # equilibrium candidate
z_star_detached = z_star.detach()     # detach: do NOT keep trajectory graph
\end{lstlisting}

\begin{remark}[Why detaching is essential]
Without detaching, PyTorch would retain the entire forward trajectory to backpropagate through it,
making memory scale as $O(K)$ and defeating the point of a DEQ. RevDEQ's reversible backward pass
reconstructs the trajectory on demand (Phase 3) using $O(1)$ saved states.
\end{remark}

\subsection{Phase 2: Boundary Lyapunov penalty via a single VJP}
\label{sec:phase2}

We now enforce that the reached equilibrium is a strict local attractor by encouraging
\[
  \rho\!\left(J_{z^\star}\right) \le \gamma < 1,
  \qquad J_{z^\star} := \nabla_z T_\theta(z^\star,x_0).
\]
Computing $\rho(J_{z^\star})$ exactly is expensive, so we use an efficient power-style proxy
requiring \textbf{one} boundary evaluation of $T_\theta$ and \textbf{one} VJP.

\paragraph{Persistent one-step power proxy (single VJP per step).}
A single VJP in a fresh random direction estimates gain in that direction, but can \emph{severely underestimate}
the true spectral radius (and thus leave the hinge penalty inactive) even when $\rho(J_{z^\star})>\gamma$.
To keep the cost at \textbf{one} VJP per step while reliably aligning with the dominant eigendirection, we maintain
a \emph{persistent} unit vector $v_{\text{buf}}$ across training steps.

At step $t$, take $v=v_{\text{buf}}$ (stop-gradient) and compute the Jacobian-transpose vector product (VJP):
\[
  v_{\text{next}} = J_{z^\star}^\top v = \nabla_{z^\star}\bigl(v^\top T_\theta(z^\star,x_0)\bigr).
\]
Then $\|v_{\text{next}}\|_2$ is a one-step estimate of local gain in the (tracked) direction.
Finally, update the buffer for the next step using a stop-gradient normalization:
\[
  v_{\text{buf}} \leftarrow \mathrm{stopgrad}\!\left(\frac{v_{\text{next}}}{\|v_{\text{next}}\|_2+\varepsilon}\right).
\]
Because this compounds across steps, $v_{\text{buf}}$ behaves like amortized power iteration and aligns with the dominant eigendirection
of $J_{z^\star}^\top$ over the course of training, without requiring $m>1$ VJPs per forward pass.

\paragraph{Penalty.}
Define a hinge loss:
\begin{equation}
  \label{eq:ljac}
  L_{\text{jac}} = \lambda_{\text{jac}}\,\max\bigl(0,\,\|v_{\text{next}}\|_2 - \gamma\bigr),
  \qquad \gamma \in (0,1).
\end{equation}

\begin{lstlisting}
# 2) Lyapunov / Jacobian penalty at detached boundary
z_b = z_star_detached.requires_grad_(True)
u   = T_theta(z_b, x0)                        # one extra forward at boundary
if v_buf is None or v_buf.shape != z_b.shape:
    v_buf = normalize(randn_like(z_b).detach())
v   = v_buf.detach()                          # persistent unit vector buffer (no grad)

# VJP: v_next = J^T v   (create_graph=True so gradients reach theta)
v_next = grad( (u * v).sum(), z_b, create_graph=True )[0]

rho_hat = ||v_next||_2                        # one-step proxy
L_jac   = lambda_jac * relu(rho_hat - gamma)

# Stop-gradient update of the persistent direction
v_buf = normalize(v_next.detach())            # or EMA-smoothed update (see Remark)
\end{lstlisting}

\begin{remark}[Why \texttt{create\_graph=True} (theoretical)]
$L_{\text{jac}}$ must produce gradients w.r.t.\ parameters $\theta$.
Since $v_{\text{next}}$ is itself a gradient w.r.t.\ $z_b$,
backpropagating through it requires mixed second derivatives (one ``extra order''),
but only for this \emph{single boundary evaluation}, not through the full trajectory.
In practice, the implementation uses a single-forward surrogate that avoids
\texttt{create\_graph=True} entirely---see Section~\ref{sec:practical} for the
compile-safe variant actually used in code.
\end{remark}

\begin{remark}[Optional: few-step power iteration]
If a tighter estimate of $\rho(J_{z^\star})$ is needed, use $m=2\!-\!5$ steps:
$v\leftarrow \mathrm{normalize}(J_{z^\star}^\top v)$, reusing the same boundary forward $u$
with \texttt{retain\_graph=True}. This increases cost linearly in $m$ but remains boundary-only.
\end{remark}

\begin{remark}[Optional: EMA smoothing + DDP note]
In practice, it can be beneficial to smooth the direction update:
$v_{\text{buf}} \leftarrow \mathrm{normalize}(\mu\,v_{\text{buf}}+(1-\mu)\,\mathrm{normalize}(v_{\text{next}}))$
with $\mu\in[0,0.99]$ and a stop-gradient update.
In DDP, maintain $v_{\text{buf}}$ \emph{per rank/device}; no all-reduce is required for correctness, since the penalty is applied per local minibatch.
If $\|v_{\text{next}}\|_2$ is numerically tiny, reinitialize $v_{\text{buf}}$ randomly to avoid a degenerate direction.
\end{remark}

\subsection{Phase 3: RevDEQ backward pass (exact unrolled gradient without IFT)}
\label{sec:phase3}

Let $L_{\text{task}}$ be the task loss computed from the equilibrium representation (Section~\ref{sec:head}).
The total objective is:
\[
  L_{\text{total}} = L_{\text{task}}(z^\star) + L_{\text{jac}}(z^\star).
\]

RevDEQ provides a reversible backward pass:
during the forward pass we discard intermediate states,
and during the backward pass we reconstruct the trajectory in reverse and accumulate gradients
without implicit-function-theorem (IFT) linear solves.

\begin{lstlisting}
# 3) Total loss and backward
L_task  = TaskLoss(Head(RMSNorm(z_star_detached)), y)
L_total = L_task + L_jac

# Backprop rule:
# - gradient of L_jac flows through boundary graph (u, v_next)
# - gradient of L_task flows through RevDEQ's reversible backward that reconstructs the trajectory
backward(L_total)
\end{lstlisting}

\begin{remark}[Correctness note]
The exact algebra for inverting the RevDEQ leapfrog updates depends on the specific reversible block design.
Conceptually, RevDEQ reconstructs $(y_k,z_k)$ in reverse using the known forward equations and recomputation of $T_\theta$.
The key property is \emph{O(1)} memory in the forward pass and \emph{exact} gradients, without IFT matrix inversion.
See \cite{revdeq} for the full reversible derivation.
\end{remark}

\section{Lyapunov stability guarantee for fixed-point convergence}
\label{sec:lyapunov}

We now give the requested rigorous definition + proof that a Jacobian spectral-radius condition yields fixed-point convergence,
while allowing maximal expressiveness (no global Lipschitz clamps).

\subsection{Definitions: stability and Lyapunov functions}

Fix an input $x_0$ and abbreviate $T(z):=T_\theta(z,x_0)$.
Let $z^\star$ be a fixed point: $z^\star=T(z^\star)$.
Define the error $e_k := z_k - z^\star$ for an iteration $z_{k+1}=T(z_k)$.

\begin{definition}[Local asymptotic stability (discrete time)]
The fixed point $z^\star$ is \emph{locally asymptotically stable} if there exists $\delta>0$ such that
for any initialization $z_0$ with $\|z_0-z^\star\|<\delta$, the iterates $z_k$ remain defined,
stay in a neighborhood of $z^\star$, and satisfy $z_k\to z^\star$ as $k\to\infty$.
If, additionally, $\|z_k-z^\star\|\le C\eta^k\|z_0-z^\star\|$ for some $C>0$ and $\eta\in(0,1)$, the fixed point is \emph{locally exponentially stable}.
\end{definition}

\begin{definition}[Lyapunov function (discrete time)]
A continuously differentiable function $V:\mathbb{R}^{B\times T\times d}\to\mathbb{R}_{\ge 0}$ is a Lyapunov function around $z^\star$ if
there exist constants $c_1,c_2,c_3>0$ and a neighborhood $\mathcal{N}$ of $z^\star$ such that for all $z\in\mathcal{N}$:
\[
  c_1\|z-z^\star\|^2 \le V(z) \le c_2\|z-z^\star\|^2,
  \qquad
  V(T(z)) - V(z) \le -c_3\|z-z^\star\|^2.
\]
\end{definition}

\begin{proposition}[Lyapunov decrease implies convergence]
If such a Lyapunov function exists, then $z^\star$ is locally exponentially stable.
\end{proposition}

\subsection{Main theorem: Jacobian spectral radius $<1$ implies local convergence}

\begin{theorem}[Lyapunov (indirect) method for fixed points]
\label{thm:lyap_main}
Assume $T$ is continuously differentiable in a neighborhood of $z^\star$ and $z^\star=T(z^\star)$.
Let $J := \nabla T(z^\star)$ denote the Jacobian (with respect to $z$).
If
\[
  \rho(J) < 1,
\]
then $z^\star$ is locally exponentially stable for the iteration $z_{k+1}=T(z_k)$.
Equivalently: there exists $\delta>0$ and $\eta\in(0,1)$ such that for all $\|z_0-z^\star\|<\delta$ we have $z_k\to z^\star$
and $\|z_k-z^\star\|\le C\eta^k\|z_0-z^\star\|$ for some constant $C$.
\end{theorem}

\begin{proof}
The proof uses a quadratic Lyapunov function derived from the \emph{discrete Lyapunov equation}.

\paragraph{Step 1: linear case and Lyapunov equation.}
Consider the linearized system $e_{k+1}=J e_k$. Since $\rho(J)<1$, the discrete Lyapunov theorem states:
for any positive definite $Q\succ 0$, there exists a unique positive definite $P\succ 0$ solving
\begin{equation}
  \label{eq:lyap_eq}
  J^\top P J - P = -Q.
\end{equation}
(One explicit solution is the convergent series $P=\sum_{i=0}^{\infty}(J^\top)^i Q J^i$, which converges because $\rho(J)<1$.)

Define $V_{\text{lin}}(e)=e^\top P e$.
Then, using \eqref{eq:lyap_eq},
\[
  V_{\text{lin}}(e_{k+1}) - V_{\text{lin}}(e_k)
  = e_k^\top (J^\top P J - P) e_k
  = - e_k^\top Q e_k
  \le -\lambda_{\min}(Q)\,\|e_k\|^2,
\]
so $V_{\text{lin}}$ strictly decreases and $e_k\to 0$ exponentially.

\paragraph{Step 2: nonlinear remainder is higher order.}
By differentiability of $T$ at $z^\star$, we have the expansion
\[
  T(z^\star+e) = z^\star + J e + r(e),
\]
where $\|r(e)\| = o(\|e\|)$ as $\|e\|\to 0$.
Equivalently, for any $\varepsilon>0$ there exists $\delta>0$ such that
\[
  \|r(e)\| \le \varepsilon\,\|e\| \quad\text{for all }\|e\|\le \delta.
\]

\paragraph{Step 3: quadratic Lyapunov function for the nonlinear map.}
Define $V(e)=e^\top P e$ with the same $P\succ 0$ from \eqref{eq:lyap_eq} (choose $Q=I$ for simplicity).
For $\|e\|\le\delta$, write
\[
  e_{k+1} = J e_k + r(e_k).
\]
Then
\begin{align*}
  V(e_{k+1}) - V(e_k)
  &= (J e_k + r)^\top P (J e_k + r) - e_k^\top P e_k\\
  &= e_k^\top (J^\top P J - P) e_k + 2 e_k^\top J^\top P r + r^\top P r\\
  &= -e_k^\top Q e_k + 2 e_k^\top J^\top P r + r^\top P r.
\end{align*}
Bound the remainder terms using Cauchy--Schwarz and $\|r\|\le \varepsilon\|e_k\|$:
\[
  |2 e_k^\top J^\top P r|
  \le 2\|e_k\|\,\|J^\top P\|\,\|r\|
  \le 2\|J^\top P\|\,\varepsilon\,\|e_k\|^2,
\]
\[
  r^\top P r \le \|P\|\,\|r\|^2 \le \|P\|\,\varepsilon^2\,\|e_k\|^2.
\]
Therefore,
\[
  V(e_{k+1}) - V(e_k)
  \le -\lambda_{\min}(Q)\|e_k\|^2 + 2\|J^\top P\|\,\varepsilon\,\|e_k\|^2 + \|P\|\,\varepsilon^2\,\|e_k\|^2.
\]
Choose $\varepsilon>0$ small enough that $2\|J^\top P\|\,\varepsilon + \|P\|\,\varepsilon^2 \le \tfrac12\lambda_{\min}(Q)$.
Then, for $\|e_k\|\le\delta(\varepsilon)$,
\[
  V(e_{k+1}) - V(e_k) \le -\tfrac12\lambda_{\min}(Q)\,\|e_k\|^2,
\]
so $V$ is a valid Lyapunov function in a neighborhood.
This implies local exponential stability of $e_k\to 0$ (standard discrete-time Lyapunov argument).
\end{proof}

\begin{corollary}[Local contraction in a Lyapunov norm]
\label{cor:local_contraction}
Under the assumptions of Theorem~\ref{thm:lyap_main}, there exists a positive definite $P$ and a neighborhood $\mathcal{N}$ of $z^\star$ such that
$T$ is a contraction on $\mathcal{N}$ in the induced norm $\|e\|_P=\sqrt{e^\top P e}$:
\[
  \|T(z)-T(z^\star)\|_P \le \eta\,\|z-z^\star\|_P,\qquad \eta\in(0,1),\ \forall z\in\mathcal{N}.
\]
Hence fixed-point iteration converges for any initialization in $\mathcal{N}$, and the fixed point is unique within $\mathcal{N}$.
\end{corollary}

\begin{remark}[What we guarantee vs.\ what we \emph{do not} guarantee]
The Lyapunov condition $\rho(J_{z^\star})<1$ guarantees:
(i) existence of a \emph{basin} around $z^\star$ where convergence is geometric, and
(ii) uniqueness of the equilibrium within that basin.
It does \emph{not} guarantee global uniqueness or global convergence from arbitrary initializations.
This is the intended trade-off to restore expressiveness.
\end{remark}

\begin{proposition}[Damped iteration preserves local stability]
\label{prop:damped}
Under the assumptions of Theorem~\ref{thm:lyap_main}, define the damped map
\[
  S_\beta(z) := (1-\beta)\,z + \beta\,T(z),\qquad \beta\in(0,1].
\]
Then $z^\star$ is also a fixed point of $S_\beta$ and is locally exponentially stable for the iteration
$z_{k+1}=S_\beta(z_k)$.

\emph{Proof.}
Clearly $S_\beta(z^\star)=z^\star$.
Let $J=\nabla T(z^\star)$ and $J_\beta=\nabla S_\beta(z^\star)=(1-\beta)I+\beta J$.
If $\lambda$ is an eigenvalue of $J$, then $(1-\beta)+\beta\lambda$ is an eigenvalue of $J_\beta$.
Using the triangle inequality and $\beta\in(0,1]$,
\[
  |(1-\beta)+\beta\lambda|
  \le (1-\beta) + \beta|\lambda|
  \le (1-\beta) + \beta\,\rho(J)
  < (1-\beta)+\beta = 1.
\]
Hence $\rho(J_\beta)<1$, so Theorem~\ref{thm:lyap_main} applies to $S_\beta$ as well. \qed
\end{proposition}

\begin{remark}[Connection to RevDEQ damping]
RevDEQ's forward updates are damped compositions of $T$ controlled by $\beta$.
Proposition~\ref{prop:damped} shows that once $T$ has a locally stable equilibrium ($\rho(J_{z^\star})<1$),
choosing $\beta\in(0,1]$ cannot destabilize that equilibrium.
Empirically, moderate damping also improves robustness when the current iterate is still outside the basin.
\end{remark}

\subsection{Link to the training objective}
\label{sec:link_training}

Theorem~\ref{thm:lyap_main} is a deterministic mathematical statement.
In training, we approximate its hypothesis by penalizing a proxy for $\rho(J_{z^\star})$ at the equilibrium reached by the solver.

\begin{proposition}[Training-time guarantee (conditional)]
If, for a given input $x_0$, the learned parameters satisfy $\rho(\nabla_z T_\theta(z^\star,x_0))\le\gamma<1$ at the reached equilibrium $z^\star$,
then $z^\star$ is a strict local attractor and the RevDEQ solve converges for any initialization within its basin (including warm starts that fall inside).
\end{proposition}

\begin{remark}[Why this recovers expressiveness]
The constraint is \emph{pointwise at equilibria on the data distribution}.
Away from equilibria, $T_\theta$ can be arbitrarily expressive (and even expansive), as long as training shapes a stable basin around the reached fixed point.
This is fundamentally less restrictive than global contraction, which caps sensitivity everywhere.
\end{remark}

\section{Head and losses (code-aligned; stability-orthogonal)}
\label{sec:head}

After the DEQ solve, we use the existing head and task losses (orthogonal to the Lyapunov guarantee).
Let $h=\mathrm{RMSNorm}(z^\star)$ and compute dual MoS logits (CTP+NTP) with FSQ:
\[
  \log p_{\text{CTP}},\ \log p_{\text{NTP}} = \mathrm{MoSHead}(h).
\]
The task loss is the standard NTP negative log-likelihood plus existing auxiliary losses:
\[
  L_{\text{task}} = L_{\text{NTP}} + \lambda_{\text{CTP}}L_{\text{CTP}}
    + \lambda_{\text{bal}}L_{\text{bal}}
    + \lambda_{\text{health}}L_{\text{health}}
    + \lambda_{\text{mos}}L_{\text{mos-ortho}}
    + \lambda_{\text{blk}}L_{\text{block-ortho-aux}}.
\]

\section{Practical notes and failure modes}
\label{sec:practical}

\paragraph{Choosing $\gamma$ and $\lambda_{\text{jac}}$.}
A typical target is $\gamma\in[0.85,0.95]$. Smaller $\gamma$ yields faster convergence but can reduce expressiveness near equilibria.
$\lambda_{\text{jac}}$ should be ramped (warm-up) so the model first learns useful representations and then sculpts stable basins.

\paragraph{Persistent-vector estimator settings.}
Maintain a unit buffer $v_{\text{buf}}$ updated as $v_{\text{buf}}\leftarrow \mathrm{normalize}(v_{\text{next}})$ with stop-gradient.
Use $\varepsilon\approx 10^{-8}$ in the normalization denominator.
Optionally smooth with EMA (Remark in Section~\ref{sec:phase2}) using $\mu\in[0,0.99]$.
If $\|v_{\text{next}}\|_2$ is numerically tiny or the tensor shape changes (e.g.\ different $B,T$), reinitialize $v_{\text{buf}}$ randomly.

\paragraph{Solver robustness knobs.}
Even with Lyapunov regularization, it is prudent to keep:
\begin{itemize}[leftmargin=2em,itemsep=0.25em]
  \item $\beta\in(0,1]$ (damping),
  \item a maximum iteration cap $K_{\max}$,
  \item an early-stop tolerance $\varepsilon$,
  \item and a fallback policy if the solver fails to converge (e.g.\ use last iterate or increase damping).
\end{itemize}

\paragraph{Multistability (multiple fixed points).}
Local stability allows multiple equilibria per input.
This can be beneficial (implicit ``modes''), but can also introduce training noise if the solver hops basins.
Warm starts and modest damping $\beta$ mitigate basin switching.

\paragraph{Implementation: two-forward approach (torch.compile + DDP compatible).}
\texttt{torch.compile} (AOTAutograd) does \textbf{not} support \texttt{create\_graph=True} (double backward)
or \texttt{retain\_graph=True} (donated buffer conflict). Furthermore, calling a compiled module with
detached inputs inside the compiled forward corrupts cached tensor metadata (SIGSEGV under DDP).

The solution is a \textbf{two-forward} approach computed \textbf{outside} the compiled model forward,
in the training loop after \texttt{loss = model(x, y)} and before \texttt{loss.backward()}:
\begin{enumerate}[leftmargin=2em,itemsep=0.1em]
  \item \textbf{Forward \#1 (VJP for $\hat\rho$ + surrogate):} Evaluate the \emph{uncompiled} block $u = T_\theta(z_b, x_0)$
        with $z_b = z^\star_{\text{detached}}.\text{requires\_grad\_(True)}$.
        Compute $v_{\text{next}} = J_{z^\star}^\top v$ via \texttt{autograd.grad(\ldots, create\_graph=False, retain\_graph=True)}.
        The \texttt{retain\_graph=True} keeps $u$'s computation graph alive for the surrogate below.
        Update $v_{\text{buf}}$ with EMA smoothing (Frobenius-normalized, $\S$\ref{sec:notation}).
  \item \textbf{Surrogate (reuses Forward \#1):}
        Compute $\hat\rho = \|v_{\text{next}}\|_F$ and
        $\text{scale}_t = \max(0, \hat\rho - \gamma) / \hat\rho$ as a pure-tensor hinge (no Python branching).
        Define surrogate $S = |u \cdot \hat{v}_{\text{next}}| \times \text{scale}_t$.
        Add $\lambda_{\text{jac}} \cdot S$ to the loss before \texttt{backward()}.
        Since $u$'s graph was retained, $\nabla_\theta S = J^\top \hat{v}_{\text{next}}$ flows to $\theta$ (first-order),
        pushing $\theta$ to shrink $T_\theta$'s output projection onto the dominant eigendirection.
\end{enumerate}
The single forward runs on the \emph{uncompiled} base model (outside the compiled graph) under
\texttt{torch.compiler.disable()}, using \texttt{create\_graph=False} and \texttt{retain\_graph=True}.
Cost: 1 extra block forward per step ($\approx 1/K$ of the DEQ solve, $\sim$8\% overhead at $K=12$).
No \texttt{.item()} GPU$\to$CPU syncs: all control flow uses pure-tensor math.

\paragraph{Theoretical guarantee (conditional).}
The power iteration in Forward~\#1 correctly estimates $\rho(J_{z^\star})$ (amortized over training steps).
The surrogate gradient is a first-order approximation to $\nabla_\theta \rho$---not exact (which would require
second derivatives), but strongly correlated.  The guarantee holds \emph{conditional} on runtime verification
that the penalty successfully drives $\hat\rho < \gamma$ on the training distribution, which is logged every step.

\subsection{True fixed-point validation (K-sweep)}
\label{sec:ksweep}

A model with a \emph{true} fixed point must satisfy: increasing solver iterations $K$ should not degrade
output quality.  Formally, if $z^\star_K$ is the solver output after $K$ iterations, then
$\mathrm{val\_bpb}(z^\star_K)$ should be monotonically non-increasing as $K$ grows (up to numerical noise).

\paragraph{K-sweep protocol.}
After training, the quantized model is evaluated at $K\in\{4,8,16,32,64,128\}$.
Two gates are checked:
\begin{enumerate}[leftmargin=2em,itemsep=0.25em]
  \item \textbf{Gross degradation}: $\max_{K\ge 16} \mathrm{bpb}_K - \min_K \mathrm{bpb}_K \le 0.1$.
  \item \textbf{Deep-K non-degradation}: for $K\in\{64,128\}$, $\mathrm{bpb}_K - \min_K \mathrm{bpb}_K \le 0.02$.
\end{enumerate}
Gate~2 is the \emph{true FP test}: a model that exploits a specific iteration count (e.g.\ $K=12$)
but degrades at $K=64$ or $K=128$ is not converging to a fixed point---it is merely fitting
the solver trajectory length.  The 0.02 threshold accounts for bf16 numerical noise.

\paragraph{Fair comparison across configs.}
When comparing architectures with different throughput (e.g.\ $A$ runs $N$ steps in time $T$
while $B$ runs $N/2$ steps in the same $T$), quality must be compared at \textbf{equal step count},
not equal wall-clock.  A larger model with more parameters per expert needs proportionally more
gradient steps to converge.  The wall-clock budget matters for competition submission, but for
\emph{architectural comparison}, step-matched evaluation is the correct protocol.
